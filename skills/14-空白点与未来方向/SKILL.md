# 指出空白点和未来研究方向的方法论 (Blank Spots and Future Directions)

> 产线位置：第14期 · 综述工位 · 上游 [annotative-vs-synthetic-writing] / 下游 [top-down-pyramid-writing]

## R — 原文 (Reading)

> "这些空白点应在文献综述中加以说明，并讨论其存在的原因。如果你发现了一个你认为应该解决的空白点，记下它，并在你规划综述时将其纳入考虑范围。"
>
> — 第5章 准则九：找出文献中的空白点

> "仅仅指出'未来需要更多的研究'是不够的；相反，你要提出具体的建议。例如，如果所有研究者都使用了自填问卷，你可能会建议未来的研究者使用其他的数据收集手段，如直接观察实际行为。"
>
> — 第9章 准则十一：提出未来研究的具体方向

> "如果你在文献综述中发现了一个值得一提的空白点，要解释一下你是如何得出这个结论的，至少也要解释一下你是如何进行文献检索的——你检索了哪些数据库，你的检索日期和检索参数是哪些。"
>
> — 第10章 准则十：为研究的空白点提供理由

---

## I — 方法论骨架 (Interpretation)

每个写综述的人都说"未来需要更多研究"——这句话因其空洞而成为学术写作中最安全的废话。这个方法教你如何从"安全废话"升级为"有信息量的未来方向"。

核心框架是**三层递进**，分布在三个写作阶段：

**第一阶段：分析阶段识别空白（第5章准则九）**

在逐篇阅读文献时，主动寻找和记录空白点。空白点是"该存在但不存在的研究"——不是"没人做过这个奇怪的组合"，而是"基于现有文献逻辑，这个方向应该有研究但确实没有"。当你注意到以下信号时，就是空白点在浮现：(1)几乎所有研究集中在同一人群（如西方大学生），某类人群完全没出现；(2)几乎所有研究用同一种方法（如自填问卷），无人尝试替代手段；(3)结果在同一变量上出现了无法解释的差异；(4)某个理论预言在大多数情境得到检验，但在某个重要情境下完全没人碰。空白点应该在电子表格笔记中专门标注。

**第二阶段：大纲中定位空白（第9章准则六）**

在建立主题大纲后，主动在**每个标题**下检查有无空白。问自己："这个主题下，有没有没有被研究的重要维度？有没有不该缺席的研究类型？"如果没有就不硬找——不是每个小标题都必须有空白点。但如果找到了，把这个空白点写进大纲的相应位置，它将成为你在综述正文中讨论该子题时的自然落点。

**第三阶段：写作中表达空白和方向（第9章准则十一 + 第10章准则十）**

把"需要更多研究"拆成三个具体动作：

1. **指出具体的空白是什么**：不是"缺乏研究"，而是"现有12篇研究中只有1篇样本含小学生，且未区分低年级和高年级"。
2. **解释为什么存在这个空白**：是研究困难（低龄儿童难以完成标准化测试）？是缺乏关注？是方法局限？
3. **提出可操作的建议**：不是"应做更多研究"，而是"建议开发适合低龄儿童的观察量表，比较1-2年级和3-4年级的差异"。

此外，**在综述开头说明你的检索策略**（数据库、关键词、时间范围），证明你声称的空白不是因为你搜得不够。这是你的"防伪证明"——如果空白在实际中存在而你不知道，至少你公开了你的检索方法，别人可以据此判断。

## A1 — 书中的应用 (Past Application)

### 案例 1：亚洲青少年应对行为的跨文化空白（例5.9.1）

- **问题**：关于青少年应对方式的研究绝大部分集中在西方样本，亚洲背景下的研究极少——这是一个典型的"人群空白"。
- **方法论的使用**：综述者在文献中明确指出了这一点："以往的研究主要基于西方文献中关于青少年应对方式的研究结果，以及他们在应对方式上存在的性别差异。相比之下，在亚洲国家，关于青少年应对方式以及性别在预测其应对方式选择中的作用的研究相对较少。"
- **结论**：综述者将自身的研究动机锚定在这个空白上："因此，本研究旨在探讨亚洲背景下的一个进修生样本的应对行为。"——空白点不仅被指出了，而且被用来证明研究的必要性。
- **结果**：空白→研究动机→研究目的，形成了一条完整的逻辑链。读者看到的不再是"没人研究过所以我研究"的简单论证，而是"西方模式未必适用于亚洲人群，现有证据不足，故需填补"。

### 案例 2：听觉记忆研究的方法论空白（第4章 + 附录B范例2）

- **问题**：关于听觉记忆和耳语证人的研究，研究者大多使用短延迟时间（几分钟到几小时），但真实的犯罪调查中，编码和提问之间可能有数天甚至一周的延迟。
- **方法论的使用**：综述者明确指出："编码和提问之间的较长保留时间被认为是犯罪调查中的一个具体的实际挑战……很少有研究利用了较长的延迟时间（最长可延迟一周）。"
- **结论**：空白点是方法论的——不是"没有研究"，而是"现有研究的时间参数不匹配实际需求"。
- **结果**：这个空白直接推动了研究者自身实验的设计方向。

### 案例 3：检索策略说明（例10.10.1）

- **问题**：研究者需要证明他们关于"父母被监禁对儿童影响"的文献检索是系统且全面的，任何声称的空白都经过充分检索验证。
- **方法论的使用**：在综述中详细说明了四种检索方法：关键词检索23个数据库 → 追踪先前综述的参考文献 → 联系65名研究者和30名纵向研究负责人 → 查阅相关书籍。
- **结论**：这种透明的检索策略说明，让读者信任"如果存在相关研究，应该已经被找到了"。
- **结果**：当综述者随后指出某些空白点时，读者不会质疑"是不是你搜得不够？"

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 写综述到了"结论"或"未来研究方向"部分不会写，只会写"未来需要更多研究"。
2. 导师/审稿人批注说"future directions太笼统，不够具体"。
3. 正在分析文献、做笔记，想知道怎么系统地在文献中找研究空白。
4. 自己的研究目的是"填补文献空白"，但不确定这个空白是否真的存在、如何论证。
5. 答辩委员会/审稿人质疑"你怎么知道没有相关研究？你是不是搜漏了？"

### 语言信号（用户的话里出现这些就应激活）

- "未来研究方向怎么写"
- "怎么找研究空白""怎么发现文献里的gap"
- "导师说我的未来建议太笼统"
- "需要更多研究不够""怎么让方向更具体"
- "怎么论证空白是真实的"
- "结论部分怎么指出文献不足"
- "我怕指出空白的时候被人说'是你没搜到'"
- "research gap""future direction""limitations"

### 与相邻 skill 的区分

- 与"文献深度分析十二准则"的区别：分析 skill 是整体——教你读懂一篇文献的全部维度（定义、数据、方法、优缺点等）；本 skill 聚焦其中一个维度（空白点识别），并延伸到大纲和写作两个后续阶段。
- 与"从笔记到主题大纲"的区别：那个 skill 教你**建大纲**；本 skill 教你在**大纲的每个节点**上做空白检查，以及在结尾部分写未来方向。
- 与 `top-down-pyramid-writing`（金字塔写作法）的区别：金字塔法覆盖全流程写作准则；本 skill 是从中抽取"空白点和未来方向"这个特定话题，做纵深展开。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **分析阶段：帮用户系统扫描空白点**
   - 对照用户的电子表格笔记或文献列表，逐一检查四个维度：
     (a) 人群/样本：是否所有研究集中在同一类人群？（如都是大学生、都是西方样本、都是临床人群）
     (b) 方法/测量：是否所有研究用同一种方法？（如都是自填问卷、都是横截面设计、都是实验室实验）
     (c) 变量/理论检验：是否有某个理论预言的变量组合从未被检验过？
     (d) 情境/条件：是否有某个重要的现实情境从未被研究过？
   - 完成标准：输出一个"已识别的空白点清单"，每个空白点包含：空白描述 + 为什么它是空白（推测原因）+ 它在文献中的位置（哪些研究涉及了但不完全覆盖）。

2. **大纲阶段：在每个标题下检查空白**
   - 如果用户已有主题大纲，针对每个主标题和子标题问："这个子主题下，有什么应该有但还没有的研究？"
   - 把找到的空白点标注在大纲对应位置。例如"III.C.大学生群体——注意：目前只有2项研究，且样本均来自单一大学"。
   - 完成标准：大纲上每个相关节点都有空白标注。如果某节点确实没有可识别的空白（该方向研究已经很充分），则标注"研究充分，无明显空白"。

3. **写作阶段：起草三层递进的空白表述**
   - 将每个空白点按三层结构展开成段落草稿：
     (a) 第一层（具体空白）："在该主题的X篇研究中，只有Y篇涉及Z群体/方法/变量……"
     (b) 第二层（原因分析）："这个空白可能是因为A、B、C等实际困难……"
     (c) 第三层（具体建议）："未来的研究可以考虑……具体建议包括……"
   - 完成标准：每个空白点的表述都包含三层，且第三层是**可被别人执行**的建议（不依赖综述者本人）。

4. **自保步骤：检索策略透明度声明**
   - 确认用户是否在综述的某个位置（通常在导言或方法部分）说明了检索策略。至少包括：检索了哪些数据库、使用了哪些关键词、检索时间范围。
   - 如果缺失，帮用户起草一段检索策略声明。
   - 完成标准：读这篇综述的人可以复现用户的检索过程。空白点声明具有"防伪性"——如果有遗漏，至少不是检索策略的问题。

5. **质量检查：避免虚假空白**
   - 检查：声称的空白点周边是否有用户确实没搜到但实际存在的研究？提醒用户：如果检索范围不够广（如只用了Google Scholar），某些空白可能是"假空白"。
   - 反问问用户："你是否尝试过以下方法确认这个空白：(a)查看过这个主题的已有综述文章？(b)检索过学位论文数据库？(c)在Google Scholar里按'被引最多'排序浏览过？"
   - 完成标准：每个声称的空白点背后都有"我搜了这些地方，没找到"的证据链。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户的综述主题极其冷门，整个领域只有3-5篇文献——此时"研究很少"本身就是结论，"找空白"没有意义。这种情况下可以把"已有的就是这些"作为结论本身。
- 用户的研究目的不是写文献综述，而是汇报自己的实证研究（如在期刊文章的"Discussion"里写limitations）——那是研究局限的讨论，不是文献综述中的空白点识别。
- 用户的综述是纯理论/哲学性的（如梳理"福柯的权力理论在当代的应用"）——这种综述的"空白"不是经验空白，而是理论对话中的"未充分讨论的连接点"，需要不同的方法论。
- 用户还没完成基本的文献检索和分析——应先调用文献深度分析 skill，完成分析后再识别空白。

### 作者在书中警告的失败模式

- **声称空白但没搜全（ce12 + 准则十）**：最危险的错误是"我找不到就等于没有"。作者强调必须在综述开头公开检索策略，让读者自行判断——这是学术诚信的问题。
- **只说"需要更多研究"不给方向（ce12）**：这是最敷衍的写法。具体建议应该是"可被另一位研究者直接拿去设计研究"的程度。
- **忽略外围研究（准则十一 + ce02）**：当某个具体问题确实没有直接研究时，不应简单地宣布"这没有研究"，而应引用相关但并非直接对应的外围文献并说明其局限。

### 作者的盲点 / 时代局限

- **对非实证学科的适用性未讨论**：全书假设综述者面对的是实证研究。对于人文社科领域（如历史学、文学批评）的综述，"空白点"可能更多是解释性空白（"没有人从这个理论视角分析过X"）而非方法/人群空白，三层框架需要调整。
- **对灰色文献和预印本生态的忽视**：2020年后，大量有影响力的研究以预印本形式在arXiv/SocArXiv传播，但这些不会出现在传统数据库中。作者说的"检索数据库→确认空白"的方法需要补充"搜索预印本服务器"这一步。
- **对"负面结果"空白的忽视**：作者未提及最常见的空白之一——"几乎所有研究都报告了显著结果，没有发表负面/无效发现"——这是发表偏倚导致的假"一致性"而非真空白。在当代开放科学运动（预注册、注册报告）的语境下，这是一个重要盲点。
- **未来方向的"可行性"判断标准缺失**：作者说"提出具体建议"但没有说怎么判断建议的可行性。实际上，建议"开发新量表"和"做跨国比较研究"的可执行性天差地别。综述者应该明确提出的建议是否在自己的能力/资源范围内——毕竟这些建议最终可能是给自己做博士论文用的。

### 容易混淆的邻近方法论

- **与"论文选题"的区别**：选题是确定"我要研究什么"；本 skill 是综述中"文献告诉我们什么还缺什么"。选题可能来自空白点，但空白点不一定是你的选题——有些空白需要比你能调动的资源多得多的资源才能填。
- **与"研究局限性"（limitations）的区别**：局限性是"我这篇研究做得不够好的地方"；空白点是"整个领域还没做的事"。前者是对自己的批判，后者是对领域的诊断。
