# 棋盘法选题定位

> 产线位置：第6期·上 · 方向工位 · 上游 [topic-refinement] / 下游 [grays-criteria-problem-evaluation]

## R — 原文 (Reading)

> "文献检索工作完成之后，你会发现棋盘上有些格子空空如也，这对你来说是个好消息，因为这表明，要么对应的研究问题还没有被研究过，要么就是对应的方法还没有被采用过。锤子是研究方法，钉子是研究课题。沿着水平的方法维度游走是为了帮手中的钉子找不同的锤子，沿着垂直的研究问题方向游走是手握锤子找钉子。如果你在棋盘当中找到一个横轴的区间和一个纵轴的区间，便为自己找到了一个品牌。"
>
> — 凌晓峰、杨强, 第4章4.3节/4.5节

---

## I — 方法论骨架 (Interpretation)

棋盘法解决的核心问题是: **你读了很多论文，但不知道自己的创新空间在哪里。**

它的做法是把一个研究领域的"已知世界"画成一张二维地图:

1. **纵轴 = 研究问题**: 把该领域内的所有子问题列出来，按相关性排列
2. **横轴 = 研究方法**: 把解决这些问题所用到的所有方法、技术、方案列出来
3. **填格子**: 把每篇已读论文放进对应的 "问题×方法" 交叉格。绝大部分论文会密集地集中在少数几个格子里
4. **空格子 = 创新机会**: 空着的格子代表 "这个研究问题还没有人用这个方法解决过"，是尚未被开采的研究金矿
5. **两个游走方向**: 横着走是"钉子找锤子"(新问题找新方法)，纵着走是"锤子找钉子"(把一个成熟方法推广到多个问题上进行比较)
6. **终极目标 — 个人品牌**: 当你在棋盘上同时占据 "横轴一个区间 + 纵轴一个区间"，你就拥有了既有锤子又有钉子的品牌区域: 同行知道你的核心方法是什么、你的核心问题是什么

棋盘法的本质不是创造新东西，而是**把你已经读过的东西系统化组织起来**，让空白区域自己浮现。你不需要凭空想创新——空格子会"替你想"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 博士生A2 — 迁移学习领域的棋盘定位

- **问题**: A2 对迁移学习感兴趣，但面对已有的众多研究论文，不知道从哪里找到自己的创新切入点
- **方法论的使用**: ① 纵轴列出迁移学习的四个子问题: 相同特征空间的知识迁移、不同特征空间的知识迁移、不平衡数据间的知识迁移、具备多个辅助领域的知识迁移。② 横轴列出四种方法: 基于实例、基于特征、集成多个模型、多个学习任务间的知识迁移。③ 将已读论文填入对应格子后发现: 大量工作集中在"基于实例的方法×相同/不同特征空间"，而"多个学习任务间的知识迁移×不同特征空间数据间的知识迁移"这个格子几乎为空
- **结论**: 这个空格子就是创新机会——用多任务迁移学习解决不同特征空间间的知识迁移问题
- **结果**: 与导师和学长讨论后确认方向可行; 发表多篇论文，顺利完成博士工作

### 案例 2: 博士生C2 — 推荐系统的棋盘定位

- **问题**: C2 对推荐系统感兴趣(偏工业应用和创业)，需要找到既有研究价值又有商业价值的方向
- **方法论的使用**: ① 纵轴列出推荐系统的四个研究问题: 基于密集矩阵的推荐、基于稀疏矩阵的推荐、使用外部本体的推荐、带有时间信息的演化推荐。② 横轴列出三种方法: 基于用户、基于产品、基于模型。③ 填完棋盘后发现: "基于模型的推荐方法×带有时间信息的演化推荐"这个格子是空的
- **结论**: 演化推荐(考虑用户兴趣随时间变化)这个问题本身有吸引力，而基于模型的方法尚未被充分探索——兼具学术创新和商业价值(在线购物网站的场景)
- **结果**: 在导师和研究者的肯定下展开研究; 用海量数据和业界公认评价方法验证效果; 成功申请专利，撰写商业计划书

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **选题困境**: 用户是研究生(硕士/博士)，读了很多论文但不知道自己的研究课题应该做什么; 感觉"所有有趣的方向都被人做过了"
2. **创新点定位**: 用户已经确定了一个大领域(如NLP、CV、推荐系统)，但需要找到具体的、尚未被充分研究的 "子问题×方法" 组合
3. **研究方向规划**: 用户正在规划自己博士几年的研究路线图，想要有策略地布局多个研究点，最终形成论文体系和博士论文主题
4. **个人品牌建立**: 用户处于博士中后期或博士后阶段，想要从"东做一块西做一块"的状态收敛到有辨识度的研究品牌，让同行知道"你=某种方法解决某类问题"
5. **文献综述的结构化**: 用户要做文献综述或开题报告，需要一个框架来系统组织已有工作

### 语言信号 (用户的话里出现这些就应激活)

- "找不到研究课题"
- "怎么找创新点"
- "所有方向都被人做过了"
- "我怎么建立自己的研究品牌"
- "读了一堆论文但还是没想法"
- "怎么找到研究的空白点"
- "不知道自己应该研究什么"
- "怎么确定博士论文的方向"
- "怎么规划几年的研究工作"

### 与相邻 skill 的区分

- 与**格雷准则选题筛选**的区别: 棋盘法负责"发现候选课题"(哪里有空白)，格雷准则负责"筛选候选课题"(哪个空白值得做)。棋盘法在前，格雷准则在后。棋盘法告诉你**可能**做什么，格雷准则告诉你**应该**做什么。一个空格子存在不代表它就是好课题——必须通过格雷准则的5条标准(明显益处、描述简单、尚无明确解法、可分解可测试、数据可靠足够)来验证
- 与**批判性创造性阅读论文法**的区别: 批判性阅读解决"如何读一篇论文并从中产生想法"; 棋盘法解决"读完几十篇论文后如何系统性组织这些知识并定位机会"。前者是单篇阅读策略，后者是多篇整合策略

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

### 第一步: 定义棋盘的维度

1. **与用户确认研究领域**: 用户当前关注的大方向是什么? (如迁移学习、推荐系统、文本生成、图神经网络等)
   - 完成标准: 一句话写出用户的研究领域
2. **拆解纵轴(研究问题)**: 引导用户列出该领域下的子研究问题，5-10个为宜。参考综述论文的章节结构、顶会论文的related work分类
   - 完成标准: 纵轴上列出至少5个子问题，按相关性排序
3. **拆解横轴(研究方法)**: 引导用户列出解决这些问题的常用方法、技术范式，4-8个为宜。注意区分方法类别(基于X的、基于Y的)，不要列具体算法名
   - 完成标准: 横轴上列出至少4个方法类，按类型排列

### 第二步: 在棋盘上填充已有研究

1. **逐一填入已知论文**: 让用户回忆已读的关键论文(5-20篇)，逐篇放入 "问题×方法" 格子
   - 每篇论文用一个编号或短标签填入对应格子，附带一句话笔记(优点/缺点/关键发现)
   - 完成标准: 至少80%的已读关键论文已填入棋盘
   - 判停条件: 如果用户说"我读的论文不够多"，建议先回到文献检索阶段，或缩小领域范围

### 第三步: 识别空白格子与评估机会

1. **标记空格子**: 在表格中标出完全没有论文的空格
   - 完成标准: 列出所有空格子，格式为 "(问题X, 方法Y)"
2. **初步筛选**: 排除明显不合理或技术上不可能的格子(如"这个问题天然不适合用那个方法")
   - 完成标准: 剩下2-5个有潜力的空格子
3. **锤子钉子分析**: 对每个候选空格子做方向判断
   - "锤子找钉子": 用户已经擅长某种方法? → 纵轴扫描，看这个方法还能解决哪些新问题
   - "钉子找锤子": 用户已经锁定某个重要问题? → 横轴扫描，看还有哪些方法没被尝试过解决它
   - 完成标准: 每个候选空格子标注了行动方向(锤子→钉子 / 钉子→锤子)
4. **导师/同行确认**: 强烈建议用户将候选的空格子与导师讨论后再开始研究
   - 完成标准: (提醒用户执行即可，agent不代为决策)

### 第四步: 个人品牌规划(可选，面向博士中后期)

1. **棋盘扫描**: 回顾已填的棋盘，用户的工作集中在哪些区域?
   - 完成标准: 在棋盘上圈出用户已有成果覆盖的区域
2. **品牌区间定义**: 找到一个横轴区间(如"基于决策树的方法族") 和一个纵轴区间(如"代价敏感学习"), 使这块矩形区域内用户有足够多的工作
   - 完成标准: 写出一句话品牌定位 —— "我用[方法区间]解决[问题区间]"

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **工程优化或产品开发**: 用户在做的是"把某个系统的准确率从95%提升到97%"，而非学术研究选题。这属于工程迭代，棋盘法帮不上忙
- **已有明确研究方向的成熟研究者**: 用户已经找到了自己的核心研究问题和方法，正在深耕中。棋盘法是选题工具，不是研究执行工具
- **纯方法论学习阶段**: 用户刚接触一个领域，论文量不足(少于5篇关键论文)。棋盘法的前提是你已经做了足够的文献检索——没有棋子，棋盘毫无意义。此时应先使用批判性创造性阅读法

### 作者的局限与时代盲点

- **2012年的学术生态**: 成书于深度学习爆发前夕，书中的案例集中在传统机器学习领域(迁移学习、代价敏感学习)。今天的大模型、GPT时代，研究方法分类体系可能完全不同。agent 应引导用户根据当前领域重新定义横纵轴，而非照搬书中的分类
- **CS学科中心主义**: 两位作者均任职于北美/香港顶尖大学计算机系，棋盘法的案例和直觉高度偏向CS。人文社科、理论物理等领域的"方法-问题"映射可能不适用——在这些领域，应先确认棋盘法的类比是否成立
- **假设了理想的研究环境**: 书中 A2、C2 的成功故事都有良好的导师指导、丰富的学术人脉、充足的数据和计算资源。现实中，用户可能面临导师放养、资源匮乏等情况。空格子找到了，但执行的能力和资源是否匹配需要用户自行评估

### 棋盘法本身的局限性

- **空格子 ≠ 好课题**: 有些空格子是空的，因为那个组合根本没有研究价值或技术上不可行。棋盘法只能告诉你"什么还没人做"，不能告诉你"什么值得做"——后者需要格雷准则来筛选
- **不替代导师判断**: 棋盘法的结果是技术性的(空白位置)，但选题还需要经验性的判断(导师的直觉、领域趋势的理解)。务必让用户与导师讨论棋盘结果
- **容易陷入"为空格而空格"**: 看到空格子就兴奋是初学者常见病。空格子需要后续验证(问题本身重要吗? 方法技术上可行吗? 数据够吗?)，不能盲目追求"不一样"
