# "注释化表述"与"综合叙述"的区分 (Annotative vs Synthetic Writing)

> 产线位置：第7期 · 综述工位 · 上游 [notes-to-outline-synthesis] / 下游 [blank-spots-and-future-directions]

## R — 原文 (Reading)

> "注释化表述是对文章内容的简要概括。在一篇综述的正文中把几个注释化表述串在一起，也许可以说明在一个主题上有哪些研究，但是它不能为读者组织材料。一篇好的文献综述是用来说明问题的，作者需要说明各个研究是如何相互关联的——它们的相对优势和劣势是什么？空白点在哪里，为什么存在？"
>
> — 第11章 准则四：追求文章清晰连贯并避免注释化表述

> "你应该在综述的开头部分明确指出包括和不包括什么（即明确你的综述范围）。"
>
> — 第11章 准则二：在综述开头明确涵盖或不涵盖哪些内容

---

## I — 方法论骨架 (Interpretation)

**注释化表述是"伪综述"的根源症状，而不是写作风格问题。** 它的本质是综述者没有完成从"读者"到"作者"的角色转换——你还在复述别人说了什么，而不是在说你自己基于文献形成了什么判断。

这个框架包含两层：第一层是**诊断**——帮你识别稿件中是否存在注释化问题；第二层是**修复**——用六条连贯性准则将注释化表述改写为综合叙述。

**诊断方法**：把你每段的第一句话（或每个段落的主题句）连起来读。如果连起来听起来像"Smith(2020)发现……Jones(2021)报告……Chen(2022)认为……"，这就是注释化——综述变成了文献目录。相反，综合叙述以**主题**驱动："关于X的发生率，不同研究给出了从4.8%到55.3%不等的估计(Smith,2020; Jones,2021; Chen,2022)，这种差异可能源于抽样方式和测量工具的差异。"

**修复方法（六条连贯性准则）**：

1. **路线图（准则一）**：长篇综述必须在导言中告诉读者：这篇综述会讨论什么、按什么顺序讨论。让读者在进入正文前就知道论证的方向。
2. **范围声明（准则二）**：明确说什么和不说什么。主题太宽、篇幅有限？直接告诉读者你划的边界在哪，别让他们猜。
3. **观点前置（准则三）**：不要把你的总体判断藏到最后——在综述开头就表达出来。不是"读完文献才形成的观点要放在最后写"——观点应该在读完全部文献后就形成了，但**写作时**要放在开头。
4. **避免注释化（准则四）**：这是核心。一个段落应该围绕**一个主题点**组织，引用多篇文献共同支撑这个点，而不是每篇文献各起一段。例11.4.1展示了多来源整合段落：一个关于法农（Fanon）学术定位的段落里，引用了Macey(2012)、Desai(2014)、Gates(1991)等多位学者的观点——但没有一个是"H某某认为……H某某认为……"的排列，而是围绕"法农到底是拉康派还是现象学/存在主义倾向"这个主题点编织叙述。
5. **子标题（准则五）**：在长篇综述中使用子标题推进论证。位置由主题大纲决定，而非随意插入。
6. **过渡词（准则六）**：用"第一、第二、第三""相比之下""与此相关"等标记讨论进展。但不要过度使用——短综述中不需要每个段落都预告下一段。

## A1 — 书中的应用 (Past Application)

### 案例 1：多来源整合段落（例11.4.1）

- **问题**：关于法农（Fanon）的学术思想归属存在多个相互竞争的观点——有人说他是拉康派，有人说他是现象学/存在主义倾向，还有人说他是"文化精神分析学家"。
- **方法论的使用**：该段落围绕一个主题点（"法农的学术定位存在争议"）组织，在一个段落中整合了五条以上的参考文献。不是"Gates(1991)认为……Macey(2012)认为……"的排列，而是"最权威的描述是他更受现象学尤其是存在主义的影响(Macey,2012; Desai,2014)。'文化精神分析学家'(Gates,1991:248)这一称谓更具说服力，因为其描述了种族化的社会生成……"——引用被嵌入到论证中，而非主导论证。
- **结论**：以主题而非作者为组织单位，让读者看到的是一场学术争论的图景，而非一串书目注释。
- **结果**：这是教科书级别的"综合叙述"示范——它证明了"一篇文章一段"不是唯一的写法，也不是好的写法。

### 案例 2：综述开头的范围声明（例11.2.1）

- **问题**：一项关于儿童听觉记忆的研究项目收集了大量数据（视觉、触觉、嗅觉、听觉），但综述者只想讨论其中听觉刺激的部分。如果不说明范围，读者会困惑"为什么其他刺激类型没讨论？"
- **方法论的使用**：在综述开头明确声明："本研究将只包括对两个声音事件的回忆和识别数据。"
- **结论**：一个简单的范围声明就排除了读者可能产生的所有疑问。
- **结果**：读者不会觉得"综述不完整"，因为他们知道这是作者有意的取舍而非遗漏。

### 案例 3：综述开头的路线图（例11.1.1）

- **问题**：一篇关于"合作激励措施与社会困境"的综述涉及多个复杂问题，读者一开始不知道文章要讨论什么。
- **方法论的使用**：在导言中用一个段落提供路线图："本报告的主要目的是对三大问题进行全面分析。首先，合作激励措施是否能促进和维持……其次，哪些变量可能影响激励的有效性？最后，奖励和惩罚在促进和维持合作能力上有区别吗？"
- **结论**：用三个以"首先/其次/最后"标记的问题，让读者在阅读正文前就知道论证将如何展开。
- **结果**：读者带着预期阅读，更容易跟上论证。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 写完了综述初稿，自己或他人反馈"读起来像文献列表，没有论点""每段都是'某某人发现了什么'"。
2. 导师/审稿人打了回来，批注写的是"更像annotated bibliography，不是literature review"。
3. 写综述时感觉段与段之间没有联系，但不知道问题在哪、怎么改。
4. 综述初稿每段只讲一篇文章，想在改写时把多篇文章整合到一个段落但无从下手。
5. 正在写长篇综述，需要确认论证是否连贯——有没有路线图、范围是否明确、子标题是否推进了论证。

### 语言信号（用户的话里出现这些就应激活）

- "我的每段都以作者名开头"
- "读起来像流水账""像文献列表""像读书笔记"
- "A发现X，B发现Y，C认为Z"
- "导师说我的综述不像综述"
- "怎么让段落之间有连贯性"
- "怎么在一个段落里引用多篇文章"
- "综述的导言应该怎么写"
- "我不知道怎么表达我的观点"
- "annotated bibliography"

### 与相邻 skill 的区分

- 与"从笔记到主题大纲"的区别：那个 skill 解决的是**写之前**的结构问题——怎么建大纲才能从根本上避免注释化；本 skill 解决的是**写完之后**的诊断和修复——已经写成了注释化，怎么改。
- 与 `top-down-pyramid-writing`（金字塔写作法）的区别：金字塔法聚焦**内容层面**（开头写什么、怎么引用里程碑、怎么处理不一致结果）；本 skill 聚焦**结构连贯性层面**（段落之间的关系、论证是否可追踪、叙述是"主题驱动"还是"作者驱动"）。
- 与 `final-self-edit-checklist`（终稿自检）的区别：自查清单是**全方位**的格式+内容检查；本 skill 是**专项**的连贯性诊断和修复。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **诊断：逐段主题句串联测试**
   - 提取用户稿件中每个段落的第一句话（或核心主题句）。如果大部分以"XXX(年份)发现/报告/认为"开头，确认为注释化问题。
   - 完成标准：能明确指出"X个段落中有Y个以作者名开头"，并给出1-2个典型示例。
   - 判停条件：如果90%以上段落已经是主题驱动的（以概念/发现/争议开头），说明用户已经做得很好，跳到步骤5做微调。

2. **检查路线图和范围声明（准则一二）**
   - 检查导言中是否告诉了读者：(a)综述覆盖哪些内容、按什么顺序？(b)明确排除了什么内容？
   - 如果是长篇综述（超过5页），导言必须有路线图。如果缺失，帮用户起草一段。
   - 完成标准：导言中有明确的"本综述将讨论A、B、C"或"首先……其次……最后"的结构，以及范围边界声明。

3. **重新组织：从"作者驱动"到"主题驱动"**
   - 对注释化最严重的段落，执行改写：先确定这个段落要论证什么主题点（一句话），然后把这个点上相关文献的发现整合进来。多位作者的观点放在括号里作为证据支撑，而不是作为段落的主语。
   - 对比展示：给出"改写前（注释化）vs 改写后（综合叙述）"的对照。
   - 完成标准：改装后的段落读起来主题句明确，每段至少整合2-3条参考文献。

4. **检查观点表达（准则三）**
   - 检查用户是否在综述开头（导言部分）明确表达了总体观点/判断。如果没有，帮用户总结一句。
   - 注意区分"应该在什么时候形成观点"（读完所有文献后）和"应该在什么时候表达观点"（综述开头）。
   - 完成标准：读者在读完导言后能说出"这篇综述的核心判断是……"

5. **检查子标题和过渡词（准则五六）**
   - 长篇综述（>3000字）：确认有子标题，且子标题来自主题大纲（而非随意插入）。检查子标题之间是否过度依赖元评论（"本文接下来将讨论……"）来连接——用论证本身推进，而非口头预告。
   - 短篇综述（<2000字）：检查过渡词是否适量，删除冗余的元评论。
   - 完成标准：读者可以从子标题序列中看到一条清晰的论证线。

6. **整体连贯性验证**
   - 最后通读：只看各级标题+每段首句——这条骨架能不能讲出一个完整故事？如果不能，回到步骤3调整组织。
   - 完成标准：标题链和首句链合在一起形成一段可独立理解的论证缩略版。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户还没有写出任何草稿——此时用户应先调用 notes-to-outline-synthesis 建立大纲、然后写初稿。注释化诊断需要实际文本。
- 用户的综述确实是要求按"逐篇讨论"的格式写的（如某些学科的"critical annotated bibliography"作业）——这不是注释化，而是不同的文体要求。
- 用户的综述已经是高质量的综合叙述，只需微调措辞——此时应调用编辑/润色类 skill，而非走完整的诊断-重构流程。
- 用户只有1-2篇文献待综述——这种极简综述确实可能只讨论单篇，不是注释化问题。

### 作者在书中警告的失败模式

- **把所有段落改成注释化后只是换了顺序（ce07）**：最常见的"假修复"——把注释从按作者字母排列改成按年份排列，但每个段落的内部结构仍然是"某作者发现……"。综合叙述的本质不是"重新排序"而是"重新编织"。
- **过度使用元评论（ce35）**：频繁说"本文接下来将讨论""如上文所述"看似增加了连贯性，实际上是在用口头指引替代真正的论证推进。短综述中尤其要克制。
- **没有表达观点就急于写（ce21 + 准则三）**：综述者可能在开头频繁使用"I will show..."，或者完全回避表达立场。正确的做法是：用内容而非作者自指来引导——"证据表明……""现有文献揭示了一个矛盾……"，而非"我认为……"。

### 作者的盲点 / 时代局限

- **对非英语母语写作者的挑战低估**：注释化表述在ESL（英语作为第二语言）写作者中更常见，因为"总结一篇文章"的语言要求低于"综合多篇文章并提出自己的判断"。本书没有针对ESL写作者给出额外的改写法训练。
- **"主题驱动"需要领域熟悉度作为前提**：作者假设综述者已经足够了解领域以至于可以在文献间建立联系。但现实中，许多学生之所以写成注释化，恰恰是因为他们对领域还不够熟悉——不敢做出跨文章的综合判断。本 skill 无法替代领域知识积累。
- **未涉及AI写作工具的影响**：在ChatGPT时代，学生可能用AI生成的"伪综合"段落——看起来整合了多篇文章，但实际上AI并不理解学科内部的争论脉络，可能把不相关的文献硬凑在一起。

### 容易混淆的邻近方法论

- **与"段落写作"（paragraph writing）教学的区别**：一般的段落写作教学强调"主题句+支撑句+结论句"的结构；本 skill 在此基础上增加了"这段论点服务于综述的什么论证目的"的判断——如果一段的主题句是"Smith(2020)做了X研究"，即使段落内部结构完美，仍然不是综合叙述。
