# 终稿自检

> 产线位置：第9期 · 正文工位 · 上游 [ten-thirty-readability-test] / 下游 [response-to-reviewers]

## R — 原文

> 这条准则被故意夸大以引起你的注意，因为它是修改过程中最重要的一条。如果一个受过教育的读者不理解你的某个观点，那么沟通过程就不会顺畅。因此，你应该经常认真思考如何修改初稿，以便让读者看得更清楚。为初稿辩解通常会适得其反。
>
> — 第12章 12.1节

> 终稿在内容、结构和体例方面应尽可能准确无误。在你仔细考虑了从同行和学术顾问那里得到的反馈，以及在你根据他们的意见修改了手稿之后，你应该仔细地最后一次编辑你的文稿。这项最终检查的目的是确保准确性。
>
> — 附录A

---

## I — 方法论骨架

本 skill = 一套心态 + 一张清单。

### 心态：读者永远是对的

当读者说"没看懂"，问题一定在作者身上，不在读者身上。三个层面：

1. **归因方向**：写作的本能反应是"你再看一遍就懂了"（辩护模式），专业作者的反应是"我的表述哪里造成了误解"（诊断模式）。
2. **诊断方法**：读者不懂不等于整篇都烂。定位具体障碍点——背景不够？术语没定义？段落间缺过渡？
3. **调和矛盾**：甲说"这节要展开"、乙说"这节删掉"时，向双方追问澄清、找到分歧根源（通常是一方误解了你的论点），然后由你裁决。注意——"读者永远是对的"≠"读者说什么就改什么"：你收到的是信号（这里让读者困惑了），不是指令（必须按读者说的方式改）。

### 清单：好的自查不是"再读一遍"，而是逐项勾选

凭感觉复查的问题在于——你已经对着这篇文章看了几十个小时，大脑会自动填补空白、忽略错误。逐项检查用外部标准取代内部感觉。检查表的组织原则是从大到小：先查内容硬伤（导言有效吗？结论立得住吗？）→ 再查结构连贯 → 然后查引文准确 → 最后查格式语法。

两个最容易被跳过的关键动作：**冷却期**（完成终稿后放几天再读，从"作者"切换成"读者"）和**格式手册的绝对遵从**（很多人因为标点拼写被退回重改，浪费一轮审阅周期）。

## A1 — 书中的应用

### 案例 1：同一组参与者被赋予四个名称
初稿中"凤凰组""第1组""实验组""最初的年轻人组"混用。不辩解说"认真看能看明白"，而是统一全程用"实验组"和"对照组"——消除了术语混乱造成的阅读障碍。

### 案例 2：导师反馈只揪格式和拼写
学生提交初稿，导师批注全在拼写错误和标题位置上。认识到导师被低级错误消耗了注意力，先自纠格式再请导师看内容——第二轮反馈获得了关于论证结构的实质性建议。

### 案例 3：两人给出矛盾反馈
学位论文委员会一人要求展开某研究的细节，另一人要求不要强调。先确认分歧是否来自对论点的误解，再协商；如果确实立场不同，作者做最终裁量——避免"全按A改"和"全按B改"的二选一僵局。

---

## A2 — 触发场景 ★

### 用户会在什么情境下需要这个 skill？

1. 收到导师/同行反馈后，第一反应是"他没理解我的意思"——需要把反应从辩护转为诊断
2. 收到来自多人的矛盾反馈，不知道该听谁的
3. 面对大量反馈意见，分不清该先改什么、怎么排优先级
4. 反复修改后陷入"饱和状态"，已经看不出还能改什么——但有"不够好"的不安直觉
5. 准备提交学位论文或投稿期刊，需要确保没有漏掉任何检查维度
6. 不确定自己的引用是否都合规——特别是直接引用是否加了引号和页码

### 语言信号

- "导师说读起来很累，但我觉得已经说清楚了"
- "A让我加这部分，B让我删这部分，我怎么办"
- "这些反馈意见太多了，从哪下手"
- "我又改了一遍但感觉跟没改一样"
- "审稿人说看不懂，但我明明写了啊"
- "我改好了，帮我最后看看""总觉得哪里不对但又说不出来"
- "导师说我格式太不规范了"

### 与相邻 skill 的区分

- 与 `top-down-pyramid-writing` 的区别：金字塔写作解决"怎么把论文写出来"；本 skill 解决"写完了怎么改到能交"。如果自查发现结构性问题，回到金字塔法重建结构。
- 与 `ten-thirty-readability-test` 的区别：10/30 检测用**外部测试者**模拟真实评审；本 skill 是**作者自己**的系统性检查。10/30 是"别人能不能看懂"的验证，自查是"我逐项确认没有硬伤"的扫描。
- 与 `response-to-reviewers` 的区别：本 skill 处理"交稿前"的自我检查，后者处理"投稿后"审稿意见的回复。心态同源（读者永远是对的→审稿人=第一读者），一个向内查、一个向外回应。

## E — 可执行步骤

### 第一部分：消化反馈（收到反馈时）

1. **转换归因方向**
   - 听到自己的辩护冲动时，引导自己问："假设读者是对的，那我的文章哪里造成了误解？"
   - 完成标准：承认"可能有我没意识到的表述问题"，而非坚持"读者应该再仔细看一遍"

2. **定位具体障碍点**
   - 逐一排查：背景信息是否足够 → 关键术语是否首次出现即定义 → 段落间是否有明确过渡 → 论证路线是否开头即预告
   - 完成标准：找出至少一个让读者困惑的具体原因，而非笼统的"整体不够清晰"

3. **对矛盾反馈走三步骤调和法**
   - 步骤A：分别追问"你具体不满意哪一点？理想的改法是什么？"
   - 步骤B：检查某一方是否因没理解核心论点而给出偏离方向的建议，如是先澄清论点
   - 步骤C：分歧仍在时作者裁决，并向被否决方解释："我选择了另一种方案，因为……"（不是"你的意见不对"）
   - 判停条件：分歧源于根本不兼容的学术立场时，如实说明取舍代价，请相关方拍板

4. **排定修改优先级**
   - 第一优先级：影响论证结构和观点传达的反馈（"核心论点看不出来"）
   - 第二优先级：影响局部清晰度的反馈（"这节跳转太突然"）
   - 第三优先级：格式和语言规范类反馈（引用格式、拼写、缩写）

### 第二部分：十组自查清单（交稿前）

**准备动作：冷却期** —— 将文稿搁置至少一天；时间不允许则至少几小时。确认自己已用"不是这篇东西的作者"的眼光看待文稿。

**第一组：导言有效性（6项）**
- [ ] 导言是否说明了综述的范围
- [ ] 导言是否指出了主题重要的原因（有具体数据或引用，而非"近年来……越来越重要"）
- [ ] 导言是否描述了论文的总体结构（论证路线图）
- [ ] 导言是否指出了将遵循的论证路径
- [ ] 导言是否说明了涵盖和不涵盖什么
- [ ] 导言中是否明确表达了你的论点或观点

**第二组：引用文献的时效性和相关性（7项）**
- [ ] 是否浏览了大多数最新文章（距今5年内）
- [ ] 综述的研究是否是最新的
- [ ] 旧文章（5年以上）是否有充分理由（里程碑研究、唯一证据来源、历史趋势追踪）
- [ ] 是否解释了为什么某些研究发现被描述为"强证据"
- [ ] 是否解释了为什么某些研究发现被描述为"弱证据"
- [ ] 是否确定了文献中的主要模式或趋势
- [ ] 引用的经典/里程碑研究是否说明了为什么是里程碑

**第三组：综述的全面性和准确性（8项）**
- [ ] 综述范围是否充分——相关子领域是否都覆盖
- [ ] 是否注意到并解释了文献中的空白点（不仅说"没有研究"，还讨论可能的原因）
- [ ] 是否说明了相关争议——对立观点各属哪一方
- [ ] 结构平行性——讨论缺点的部分是否也讨论了优点
- [ ] 是否注意并解释了研究之间的关系（最早/相似/对立）
- [ ] 是否指出了关键术语或概念的来源
- [ ] 正文是否有空白点——开头承诺讨论但正文没出现
- [ ] 省略了某个相关问题时是否向读者解释了原因

**第四组：连贯性和流畅性（8项）**
- [ ] 每项研究是否与主题大纲相符
- [ ] 是否删除了与论证路径无关的引用
- [ ] 论证路径在整篇中是否始终清晰
- [ ] 每一部分是否与前一部分逻辑连贯
- [ ] 元评论（"本文下一部分将介绍…"）是否必要
- [ ] 子标题是否有助于推进论证——读子标题列表能看出故事的起承转合
- [ ] 长综述没有子标题是否应该加
- [ ] 过渡手段是否足够（连接词、总结句）

**第五组：结论的有效性（2项）**
- [ ] 结论是否为读者提供了答案——一两句话总结"读完这篇综述我们对主题知道了什么"
- [ ] 结论是否回应了导言提出的论点

**第六组：引文和参考文献的准确性（7项）**
- [ ] 是否查阅了格式手册中关于叙述性引用的指南
- [ ] 正文每一条引文是否都在参考文献列表中有对应条目
- [ ] 参考文献每一条是否都被正文引用过——没有"只读过没引用"的幽灵条目
- [ ] 是否删除了未经引用的参考文献条目
- [ ] 参考文献中大多数研究的日期是否较近
- [ ] 正文日期和参考文献日期是否完全一致（同作者同年份文章易错）
- [ ] 作者姓名拼写是否前后一致

**第七组：文稿的格式和整体准确性（6项）**
- [ ] 是否仔细通读并编辑了整个文稿
- [ ] 是否运行了最后的拼写检查
- [ ] 页边距是否恰当（通常2.54厘米）
- [ ] 所有页面是否都已编号
- [ ] 文稿是否双倍行距
- [ ] 文稿是否署有作者全名

**第八组：格式及语言使用的得体性（18项）**
- [ ] 是否仔细阅读了对应领域的格式手册（APA/MLA/GB-T 7714等）
- [ ] 文稿与格式手册的要求是否逐条一致
- [ ] 标题是否符合格式手册规定
- [ ] 拉丁文缩写（i.e., e.g., etc.）是否仅限括号内使用
- [ ] 长引语（超过3-4行）是否确有存在必要——能否转述替代
- [ ] 每条引语是否对综述有重大贡献
- [ ] 重要关键术语是否避免了同义词——同一概念从头到尾叫同一个名字
- [ ] 创制新词是否在首次使用时加了引号标记
- [ ] 是否避免了俚语、口语和习语（thing→item, a lot→many）
- [ ] 是否避免了缩写形式（can't→cannot）
- [ ] 是否加入了任何与论证路径无关的注释化表述
- [ ] 是否避免了"一串注释化表述拼在一起"的写法
- [ ] 所有缩写词首次出现时是否拼全了全称
- [ ] 第一人称的使用是否恰当
- [ ] 是否避免了性别歧视语言
- [ ] 0-9的数字是否拼写、10及以上是否用数字
- [ ] 句子开头的数字是否拼写完整
- [ ] 中文语境补充：的/地/得、中英文标点混用、全角半角是否检查过

**第九组：语法的准确性（8项）**
- [ ] 是否检查了全文的语法正确性
- [ ] 每一句是否都是完整的句子（大声朗读测试：读到一半需停顿重组处需重写）
- [ ] 是否避免了间接结构和被动语态
- [ ] 时态是否一致（研究发现用现在时，历史关系用过去时）
- [ ] 逗号和其他标点是否正确
- [ ] 是否避免了复杂句式
- [ ] 长句（超过几行）是否已拆分
- [ ] 长段落（一页或更长）是否已拆分为两段以上

**第十组：非英语母语者额外检查（5项，如适用）**
- [ ] 是否请了校对员帮查英语
- [ ] 冠词用法（a, an, the）
- [ ] 介词用法（in/on/at/for等）
- [ ] 主谓一致性
- [ ] 惯用表达是否正确

### 最终步骤

- 如果还有一天以上时间：放一两天再全文通读一遍
- 如果有条件：请至少一个人评阅——自己看不出问题，别人一眼看到
- 评阅人提出问题后：逐一解决、调和分歧、做自己的决定，不直接拒绝任何反馈而不给理由
- 完成标准：对文稿的每一个维度——从论点是否站得住到最后一个标点是否正确——都有充分信心

## B — 边界 ★

### 不要在以下情况使用此 skill

- 初稿尚未完成——本 skill 的前提是"已经有东西可以给别人看了"
- 反馈只是纯格式纠错（"这里少了一个逗号"）——直接对照格式手册修改，不需要心态转换
- 反馈来自非目标读者（请完全不了解领域的人看技术细节）——"读者永远是对的"前提是该读者具备该领域的基本阅读能力
- 初稿尚未完成就提前"边写边查"——检查表是为终稿设计的；写初稿阶段的主要矛盾是"写出来"，不是"写完美"

### 作者在书中警告的失败模式

- **为初稿辩解**："你再仔细读一遍就懂了"——最常见失败，辩解不会让文章变好
- **先改格式再管内容**：改完容易的格式问题就觉得自己"已经处理了反馈"，核心内容问题丝毫未动
- **"照单全收"所有反馈**：不评估每条反馈的价值全部改——文章失去自己的声音，可能改出更混乱的版本
- **跳过冷却期直接交**：你还在"作者"模式中，看不到自己的盲点
- **格式错误把导师的注意力全耗掉**：导师被迫花所有时间纠错而不是评内容——最浪费反馈机会的行为
- **剽窃的无意识形式**："引用了原文但没加引号"和"改了结构换了词但没注明出处"同样是剽窃
- **只用拼写检查而不通读**：自动工具抓不住音近错误和逻辑问题
- **参考文献列表和正文脱节**：最容易被退回的格式硬伤

### 作者的盲点 / 时代局限

- **2017年原书未涉及AI写作工具**：AI辅助写作的伦理（如何标注AI协助内容）需另寻最新指南；但"读者永远是对的"心态同样适用于用AI模拟读者视角检查文章
- **格式手册以APA为核心**：中国学位论文多用GB/T 7714，具体条款需替换为对应手册规定
- **假设写作是英文的**：中文综述的语法检查维度完全不同（的/地/得、中英文标点混用），已在第八组补充
- **假设反馈来源是善意的**：现实中学位委员会成员可能因学术立场分歧给出"战略性"反对意见——这种反馈不是"读者不懂你的文章"，而是"读者不同意你的立场"，需要用调和三步骤的判停条件处理

### 容易混淆的邻近方法论

- **终稿自查 ≠ 校对/润色**：校对只解决拼写语法，自查覆盖从论点逻辑到格式规范的十个维度
- **自查表 ≠ 写作规范大全**：它是"检查工具"而非"写作指南"——告诉你检查什么，怎么改要回到对应的写作准则 skill
