# 区分"论断"与"证据"的推理方法

> 产线位置：第5期 · 精读工位 · 上游 [deep-article-analysis] / 下游 [topic-refinement]

## R — 原文

> 文献综述中的一个常见错误是把作者的论断当成研究发现
> 来报告。为了避免这个错误，请确保你已经理解了作者的证据
> 及其解释。一项研究的发现来自其所提供的经验证据，论断则
> 是作者的观点。
>
> — 第5章 5.7节

---

## I — 方法论骨架

学术文章的正文不是一块均匀的"事实"——它是论断（作者的个人判断、
解释、推测）和证据（数据、统计分析结果、系统观察记录）的混合体。
综述者的核心任务是拆开这两种东西，然后分别处理：证据需要被准确转述，
论断需要被标定和评估。一个简单的诊断方法是逐句问自己"这句话是基于
数据，还是基于作者的个人推理？"如果是前者，你需要在综述中用
"发现""表明""数据显示"等词报告；如果是后者，你需要在综述中用
"推测""认为""建议"等词标记，并且在心里把它的可信度降一级。
如果作者的论断明显超出了证据的范围（如20名大学生的实验结果被推广
到"所有青少年"），那这就是一个你需要指出的方法论缺陷。该方法
不是让你怀疑一切——它是让你对文章建立精确的信任感：知道哪些部分
可信度高、哪些部分只是作者的"有根据的猜测"。

## A1 — 书中的应用

### 案例：节食与暴饮暴食的论断与证据（c25，例5.7.1）
- **问题**：一篇关于暴饮暴食风险因素的文章，读者如何区分哪些是
  理论推测、哪些有数据支撑
- **方法论的使用**：作者逐句展示了以下三层结构——
  *论断层*：前三分之二篇幅，"节食被认为会增加个人为抵消热量匮乏的
    影响而过度进食的风险""节食也可能会因为违反严格的饮食规则……
    促进暴饮暴食""此外，节食需要从依赖生理信号转向……认知控制"——
    这些是理论推理，使用了"被认为""可能会"等推测性语言
  *过渡层*：一句话标明即将切换——"可以证明这些论断正确性的是……"
  *证据层*：最后一句给出具体的研究引用——"通过节食可以预测青春期
    女孩暴饮暴食的发生(Stice & Agras, 1998)，以及急性热量剥夺会导致
    成年女性暴饮暴食(Agras & Telch, 1998)"
- **结论**：即使在一段文字里，论断和证据也可以清晰分开。关键是识别
  语言信号（"被认为""可能会""可以证明"）和追踪引用来源的出现位置

## A2 — 触发场景 ★

### 用户会在什么情境下需要这个 skill？

1. 读了一篇实证研究，想在电子表格里区分"这篇文章发现了什么"和
   "这篇文章的作者认为什么"
2. 准备写综述，不确定某篇文献里的某句话是该作为"研究发现"引用，
   还是该标记为"作者观点"
3. 看到两篇结论相反的文章，想知道哪篇的证据更强
4. 导师反馈"你不能把作者的观点当事实写进综述"

### 语言信号

- "这篇文章的结论有多可信"
- "怎么区分研究发现和作者观点"
- "哪些是数据哪些是作者自己说的"
- "这篇文章说XX有效，但我该不该照单全收"
- "论断和证据的区别是什么"

### 与相邻 skill 的区分

- 与 `deep-article-analysis` 的区别：本 skill 专注展开12准则中的
  准则七（区分论断和证据），提供逐句推理的诊断工具；后者是全部
  12条准则的整体框架
- 与 `research-quality-checklist` 的区别：本 skill 关注的是
  "文章里说的东西属于哪种陈述类型"，后者关注的是"研究方法本身
  做得好不好"——两个维度互不影响但都影响可信度综合判断
- 与 `evidence-backing` 的区别：本 skill 是分析**单篇**文章内部的
  论断-证据结构，后者是在**多篇**文献中搜寻支撑某个外部论点的证据

## E — 可执行步骤

1. **通读一段文字，用不同颜色或标注将陈述分为两类**
   - 找"证据"：有具体数据的句子（数字、百分比、p值、效应量），
     或明确标注了研究方法来源的描述（"在全州调查中……""对随机
     样本的分析显示……"）
   - 找"论断"：使用了推测性动词（认为/推测/可能/似乎）、无数据
     支撑的因果解释（"这可能是由于……"），或出现在讨论/结论部分
     而非结果部分的陈述
   - 完成标准：至少找出了一段文字中1条证据和1条论断，做了标注

2. **对每条论断做"溢出检查"——论断是否超出了证据的范围？**
   - 自问：证据的样本是谁（大学生？全国成年人？）、在什么条件下
     （实验室？教室？）、测量的是什么（态度？行为？成绩？）
   - 再问：论断是否把这些发现推广到了样本之外的群体、条件或变量上？
     如果是，这个推广有没有数据支撑？
   - 完成标准：对每条论断给出了"有超出/未超出"的判断，并记录理由

3. **判断证据的强弱程度**
   - 强证据特征：大样本、随机分配、全国代表性、高信度/高效度测量、
     大效应量
   - 弱证据特征：小样本、方便样本、未报告信效度、仅统计显著但效应量小
   - 完成标准：对找到的证据给出了"强/中/弱"的判断，写在电子表格评论列

4. **在综述中区分表述：用动词标记信息来源的性质**
   - 描述研究证据时用："发现""表明""结果显示""数据证实"等
   - 描述作者个人观点时用："推测""认为""建议""指出（未提供实证数据）"等
   - 完成标准：在综述初稿中，至少检查了5个引用的句子，确认动词与被引用
     内容的信息类型匹配

## B — 边界 ★

### 不要在以下情况使用此 skill

- 在快速预读阶段——此时不需要逐句区分，只需获得文章全局印象
- 处理非实证性文章（纯理论文章、社论、立场声明）——这些文章本质上
  就是论断的集合，区分论断与证据的意义有限
- 当文章已经提供了明确的"结果"和"讨论"分节时——大部分实证研究
  的架构自带区分（结果=证据为主，讨论=论断为主），但讨论中也可能
  混入对额外分析结果的描述，仍需留意边界

### 作者在书中警告的失败模式

- **把论断写成研究发现**（ce03）：在综述中写"X研究证明了Y"而原文
  并未直接测量Y——这是综述最常见、最严重的错误之一
- **讨论实证研究结果时使用"证明"一词**（ce05）：作者反复强调
  "千万不要使用'证明'这个词"，实证研究只提供不同程度的证据，
  不"证明"任何东西

### 作者的盲点 / 时代局限

- **忽视论断的价值**：作者倾向把"论断"当作需要警惕的东西。
  但实际上，优秀论文的论断部分（特别是理论推断和未来方向建议）
  往往最富启发性。这本 skill 教你区分，不是教你蔑视论断——
  好的论断是下一代研究问题的种子
- **未区分不同类型的论断**：理论推断（有逻辑链支撑的）vs 过度
  推广（溢出了证据范围但没说）vs 价值判断（"这一发现对社会
  有重大意义"）——三者的可信度和处理方法完全不同，但作者未细分

### 容易混淆的邻近方法论

- **"区分主要来源和次要来源"**：那是说信息来源的层级（一手vs二手），
  本 skill 是说同一条一手来源内部的陈述类型
- **事实核查（Fact-checking）**：事实核查是查"这个数据是不是真的"，
本 skill 是查"这句话到底在说什么类型的东西"——你不需要验证数据，
只需要识别陈述的类别
