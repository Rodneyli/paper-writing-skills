# 文献深度分析十二准则

> 产线位置：并入第4期 · 精读工位 · 上游 [spreadsheet-note-system] / 下游 [claim-vs-evidence]

## R — 原文

> 现在，你已经初步完成了对所收集文章的分析……现在，
> 你需要通过从每篇文章中提取更具体的细节来进一步扩展你的
> 分析。这将帮助你以更有效的方式组织你的材料。本章将帮助
> 你完成这一过程。
>
> — 第5章 开篇

---

## I — 方法论骨架

这篇参考文献综述的核心工具是一套结构化的"分析镜头"。你不是
带着空白的大脑去读一篇文章，"应该从哪个角度看"已经有了12个
明确方向。这12条准则可以分为三层：第一层（准则一到四）是
**信息提取**——找定义、找统计数据、找前人综述、找可引用的段落；
第二层（准则五到八）是**质量判断**——找方法的优点和缺陷、区分
文章里的论断和数据、识别跨研究的大趋势；第三层（准则九到十二）是
**定位与综合**——找文献中的空白点、发现文章之间的关系、评估每篇
对你自己主题的贴合度、检查参考列表是否足够新。这三层从"这篇文章
说了什么"到"这篇文章有多可靠"再到"这篇文章在我的整理图景中
处于什么位置"，逐层深入。这12条准则既是读一篇文献时的检查清单，
也是你在电子表格笔记的"评论"列里要写的内容来源。它解决的核心
问题是：模糊的"批判性阅读"到底该干什么。

## A1 — 书中的应用

### 案例1：传统霸凌与网络霸凌的定义对比（c15，准则一）
- **问题**：网络霸凌是新兴主题，不同研究对它有不同定义
- **方法论的使用**：作者对比了奥维斯(1993)的传统霸凌定义
  （反复暴露于负面行动）与网络霸凌定义（通过电子通信手段的重复性
  故意伤害），并指出关键差异——"网络霸凌不需要面对面对抗"
- **结论**：找准定义差异不仅澄清概念，还可指导后续的分组分析

### 案例2：节食与暴饮暴食的论断vs证据（c25，准则七）
- **问题**：文献中大量论述"节食导致暴饮暴食"，但需要区分哪些是
  理论推测、哪些有数据支撑
- **方法论的使用**：作者展示了段落前三分之二是论断（"节食被认为
  会增加……""节食也可能会……""此外，节食需要……"），最后一句
  才是证据（"可以证明这些论断正确性的是……Stice & Agras, 1998"）
- **结论**：即使是权威期刊的文章，推断性语言和实证结果也混在一起，
  综述者必须拆开

### 案例3：指出文献中的亚洲背景空白（c27，准则九）
- **问题**：综述青少年应对行为时发现研究集中在西方样本
- **方法论的使用**：明确记录"以往研究主要基于西方文献……相比之下，
  在亚洲国家，关于青少年应对方式以及性别在预测其应对方式选择中的
  作用的研究相对较少"
- **结论**：空白点要具体到"什么人群、什么变量没被研究"，而非泛泛
  说"研究不够"

## A2 — 触发场景 ★

### 用户会在什么情境下需要这个 skill？

1. 刚开始写文献综述，读了几篇但不确定是否"读透了"
2. 导师或审稿人反馈"文献分析深度不够"，需要可操作的改进标准
3. 在电子表格笔记的"评论"列不知道该写什么
4. 想比较几篇同主题文献但不知道从哪些维度对比

### 语言信号

- "我怎么判断一篇文章好不好"
- "读完一篇论文，应该提取哪些信息"
- "导师说我文献分析不够深入，怎么办"
- "文献综述不知道怎么分析文章"
- "批判性阅读具体怎么做"

### 与相邻 skill 的区分

- 与 `spreadsheet-note-system` 的区别：本 skill 告诉你**分析什么**
  （内容），后者告诉你**怎么记录和组织**分析结果（工具架构）
- 与 `claim-vs-evidence` 的区别：本 skill 是完整的12条分析维度，
  后者只深入展开其中的准则七（论断vs证据），是本 skill 的一个子项的
  深度展开
- 与 `research-quality-checklist` 的区别：本 skill 的准则五
  和准则六（找方法优缺点）是上层指引，后者是具体到定量/定性研究的检查项

## E — 可执行步骤

以下12条准则即执行步骤。读完一篇文献后，逐条完成。每条完成后
在电子表格笔记中留下记录。

### 第一层：信息提取

1. **准则一：寻找关键术语的明确定义**
   - 文章定义了几个核心概念？是作者自己的定义还是引用他人的？定义是否有争议（不同文章不一样）？
   - 完成标准：在笔记中记下了至少一个关键术语的完整定义（含出处）

2. **准则二：在文献综述开头寻找关键的统计数据**
   - 文章中有没有全国性调查数据、患病率、百分比的精确数字？这些数据对你自己的综述开头有没有用？
   - 完成标准：在笔记中记录了一个可能有用的统计数据，含数字和出处

3. **准则三：特别留意并引用已有的文献综述文章**
   - 这篇文章是不是综述文章？如果是，它的结论是什么？和你自己的综述方向有何异同？
   - 完成标准：判断了文章类型，如果是综述文章，已概括其核心结论

4. **准则四：记下简短但重要的直接引语**
   - 有没有一两句特别精辟的定义或表述，值得在综述中直接引用？有没有法律条文等需要精确措辞的内容？
   - 完成标准：如有可引用的原文，已准确抄录并标注页码

### 第二层：质量判断

5. **准则五：寻找方法上的价值**
   - 这篇文章的方法有什么优势？样本够大吗？是全国性样本吗？是随机分配吗？有没有创新的测量工具？
   - 完成标准：至少指出一个方法论优势，写在评论列

6. **准则六：寻找方法上的缺陷**
   - 样本小吗？不是随机抽样？测量工具没报告信度和效度？没有对照组？
   - 完成标准：至少指出一个方法论缺陷，写在评论列

7. **准则七：区分论断和证据**
   - 把文章中的陈述分成两类：有数据支持的（证据）vs 作者个人判断的（论断）。检查论断是否超出了证据的范围
   - 完成标准：至少找到一处论断与证据的界限，标注哪个是论断、哪个是证据

8. **准则八：识别以往研究结果中的主要趋势或模式**
   - 如果读的是综述，它总结出的主要趋势是什么？如果读的是实证研究，它的结果与大部分同主题研究一致还是矛盾？
   - 完成标准：用一句话概括该研究在文献整体趋势中的位置

### 第三层：定位与综合

9. **准则九：找出文献中的空白点**
   - 作者自己有没有指出还有哪些问题没解决？有没有某个人群/方法/变量从未被研究过？
   - 完成标准：记录下至少一个具体的空白点

10. **准则十：识别各项研究之间的关系**
    - 这篇文章与你已读过的其他文章是什么关系？是里程碑→跟随？是支持还是反驳？是同一问题不同人群？
    - 完成标准：在评论列标注了该文与你已读文献的至少一种关系

11. **准则十一：评估与主题的相关程度**
    - 这篇文章是对你的主题的直接研究，还是只能作为外围支撑？如果是外围的，标注清楚
    - 完成标准：给出了相关度判断（直接/外围/不相关），并标注理由

12. **准则十二：评估参考文献列表的时效性和覆盖面**
    - 参考文献多以哪一年的为主？有没有漏掉你已知的重要文献？最老的和最新的分别是什么时候？
    - 完成标准：快速扫过参考文献列表并作出"时效性可以/需要注意"的判断

## B — 边界 ★

### 不要在以下情况使用此 skill

- 预读筛选阶段——此时只需要判断文章是否值得精读，不需要完整的12条分析
- 文章与你自己的主题无关——不需要对无关文章做深度分析
- 已经通过其他系统（如导师的指导）建立了等效的分析流程——不重复建设

### 作者在书中警告的失败模式

- **把论断当证据复述**（ce03）：最常见的错误，把"作者认为"写成
  "研究发现"，等于把个人观点升级为科学结论
- **过度使用直接引语**（ce04→更准确是ce15）：综述的本质是原创综合，
  直接引语应限于经典定义和法律条文，"长引语几乎总是不适当的"
- **只读摘要就引用**（ce01）：摘要缺乏方法细节和局限讨论，只读摘要
  就引用是不负责任的——"完整地阅读每一篇自己引用的参考文献是你的
  道德责任"

### 作者的盲点 / 时代局限

- **12条准则不区分文章类型**：实证研究文章、理论文章、综述文章的分析
  重点各不相同，但准则对三者一视同仁。对纯理论文章来说，五到八（方法
  论相关）适用性有限
- **没有涉及AI辅助分析**：2023年后LLM可以做初筛、摘要生成、甚至帮你
  标注论断vs证据。12条准则的部分步骤可以被AI加速，但最终判断仍需
  人工确认

### 容易混淆的邻近方法论

- **与"读论文的标准步骤"（摘要→引言→方法→结果→讨论）**：那是
  阅读顺序（怎么读），本 skill 是分析框架（读出什么）
- **与研究方法课程**：本 skill 不教你统计方法或研究设计原理，
只告诉你怎么从综述者的角度去审视一篇已经写完的报告
