# 电子表格文献笔记系统

> 产线位置：第4期 · 精读工位 · 上游 [critical-creative-paper-reading] / 下游 [deep-article-analysis]

## R — 原文

> 汇编笔记最有效的方法是将笔记输入计算机中的电子表格程序或表格中。
> 例4.5.1列出了一组起步时常用的项目：作者姓名、文章标题、出版年份、
> 期刊、分组标识符、摘要、方法论、研究发现、评论。
>
> — 第4章 4.5节，第8章

---

## I — 方法论骨架

文献综述不是一次性读完全部文章再凭记忆写出来。你需要在读每一篇时
把关键信息拆成若干固定维度，逐一填入电子表格的对应列中。这九列构成了
一个"强制分析框架"：前四列（作者/标题/年份/期刊）是基本信息，分组
标识符帮你未来按主题排序，摘要要求你用自己的话提炼而非复制粘贴，
方法论和研究发现两列让你必须面对"这篇文章到底做了什么、得出什么"，
评论列则逼你给出自己的判断。当表格填完并按"分组标识符"列排序后，
你会发现同一主题的文献自然聚在一起——这就是从"读了一堆"到"知道
怎么组织"的关键转折。第8章进一步把表格拓展为定义表（梳理关键概念
的不同定义及其演变）和方法表（对比不同研究的实验设计、抽样方式），
让表格不仅是笔记工具，也是最初级的综合工具。

## A1 — 书中的应用

### 案例1：通用九列起步模板
- **问题**：读文献时不知道记录什么、记多少才够
- **方法论的使用**：作者给出例4.5.1九列标准模板（c14），
  起步先填前四列最基础信息，分组标识符根据预读时的分类进入，
  方法论和研究发现两列用一致的描述符来写（如"公立vs私立""证实vs证伪"），
  评论列用于标注里程碑式研究、可引用的表格等
- **结论**：这套列标题不仅记录信息，更重要的是强制执行分析——
  你不得不回答"这篇文章方法是什么""发现了什么""我的评价是什么"

### 案例2：定义表——控烟心理赋权（c45）
- **问题**：一个变量（心理赋权）有多个维度（内省的/互动的），
  散落在不同文献的定义中
- **方法论的使用**：建一张定义表，把"内省的"维度（特定领域的效力、
  感知到的社会政治控制、参与能力）和"互动的"维度（资源知识、自信、
  倡导）分别整理
- **结论**：表格让多维度概念的结构一目了然

### 案例3：方法表含结果摘要——宗教与青少年性行为（c48）
- **问题**：需要对比多项纵向研究的设计、样本和结果
- **方法论的使用**：建一张综合表，列包括出版日期/作者、地点/年份/
  社会经济地位/样本量/年龄、宗教性测量、性行为测量、宗教对性行为的影响
- **结论**：在方法信息之外加一列结果摘要，读者可以跨研究直接对比

## A2 — 触发场景 ★

### 用户会在什么情境下需要这个 skill？

1. 已搜集了10+篇论文，笔记散落在多个工具里，想开始写综述但不知道从哪下手
2. 导师反馈"你读的文献不少，但没有系统对比和分析"
3. 需要比较不同研究在方法、样本、结果上的异同，但大脑装不下了
4. 准备写综述的方法论部分或讨论部分，需要快速抽取所有文献的方法细节

### 语言信号

- "笔记太乱了，不知道怎么整理"
- "读了20篇论文，写综述时忘了哪篇说了什么"
- "帮我建一个文献笔记的表格"
- "怎么系统化管理读过的文献"
- "我有EndNote里的文章，但笔记没法统一"

### 与相邻 skill 的区分

- 与 `deep-article-analysis` 的区别：本 skill 关注的是**怎么记录和
  组织**分析结果（表格架构），后者关注的是**分析什么**（12条分析准则）
- 与 `notes-to-outline-synthesis` 的区别：本 skill 是前置步骤（建表→
  填表），后者是后续步骤（从填好的表格中提取信息→重组为论证大纲）

## E — 可执行步骤

1. **创建电子表格，按九列设置列标题**
   - 列标题：作者姓名 / 文章标题 / 出版年份 / 期刊 / 分组标识符 /
     摘要 / 方法论 / 研究发现 / 评论
   - 完成标准：电子表格文件已创建，九列标题全部就位

2. **为所有已筛选的文献填写前四列**
   - 作者姓名、文章标题、出版年份、期刊——这是最基础信息，先统一完成
   - 完成标准：每篇目标文献在表格中占一行，前四列全部填充完毕

3. **按预读阶段的分类填写分组标识符**
   - 将每篇文章归入一个子主题类别（如"CBT干预""药物治疗""混合方法"）
   - 完成标准：每行都有分组标识符，且同一分组的文章在排序后聚在一起

4. **逐篇填写摘要、方法论、研究发现**
   - 摘要：用自己的话概括（不要复制粘贴原文摘要）
   - 方法论：使用一致的描述符（如"问卷调查""随机对照实验""民族志访谈"）
   - 研究发现：聚焦经验证据，不写作者的个人推测
   - 完成标准：三列对每篇文章都已有内容，不是空白

5. **填写评论列——给出你的判断**
   - 标注里程碑式研究、方法优势/缺陷、与其他文章的矛盾或互补关系
   - 完成标准：每行的评论列至少有一条简洁的判断

6. **如有需要，扩展为定义表或方法表（第8章）**
   - 定义表：当关键术语有多个不同定义时，整理各定义的出处和内容
   - 方法表：对比各研究在实验设计、抽样方式、样本量上的差异
   - 完成标准：定义表或方法表已经创建，作为电子表格的新工作表或独立表格

## B — 边界 ★

### 不要在以下情况使用此 skill

- 文献少于5篇——电子表格的开销超过收益，普通笔记即可
- 只是为了"存档"而非为写综述做准备——本 skill 的核心是分析驱动，
  不是文献管理软件替代品
- 已有一个结构良好的笔记系统且能有效提取信息时——不做重复建设

### 作者在书中警告的失败模式

- **把原始摘要复制粘贴到"摘要"列**（ce01）：没有自己的提炼和分析，
  等于没读。摘要列必须用自己的话写
- **文献综述变成表格集合**（ce14）：电子表格是你为自己做的分析工具，
  不是直接贴进综述的"成品"。终稿中表格应限于读者难以理解的复杂材料
- **笔记不一致，无法跨文章对比**（第4章）：如果"方法论"列对A文写
  "问卷调查"、对B文写"邮件发了问卷"，描述符不统一就失去了对比价值

### 作者的盲点 / 时代局限

- **工具已迭代**：作者推荐的是Excel/电子表格，但Zotero 7的
  高级标注和Notion等工具在灵活性上远超基础表格。核心原则
  （按列强制分析）仍有效，但具体实现工具可自由选择
- **未涉及协作场景**：现代研究常多人协作，但书中假设单人建表。
  多人共享编辑时需额外约定描述符的一致性

### 容易混淆的邻近方法论

- Zotero/Mendeley的文献库管理：这些工具帮你"存"文献，本 skill 帮你"拆"文献——
  区别在于是否强制逐维度分析
- 文献综述的正文叙述：表格是你的后台数据库，正文是前台展示。两者不应该混同
