# 证据思维

> 产线位置：并入第2期 · 筛选工位 · 上游 [preread-classify-deepread] / 下游 [critical-creative-paper-reading]

## R — 原文

> 有理由认为，所有的实证研究都是有缺陷的。因此，通过研究获得的结果应谨慎解释。……在讨论实证研究的结果时，千万不要使用"证明"这个词。实证研究不能提供证明，而是提供了不同程度的证据，有些研究提供了比其他研究更有力的证据。
>
> — 何塞·L.加尔万 & 梅丽莎·C.加尔万, 第1章、第6章(准则十三)

> 你可能很快就会发现自己就像一个陪审员一样，讨论哪位研究者的论点最具有连贯性和逻辑性，哪位研究者的证据最有力，等等。这可能是一项困难但有趣的活动。
>
> — 同上, 第1章

---

## I — 方法论骨架

证据思维 = 一个认知前提 + 一个操作角色模型。认知前提告诉你**为什么不能轻信**，陪审员模型告诉你**知道之后怎么做**。

### 认知前提：所有实证研究都有三类天生缺陷

这不是方法论水平问题，而是任何研究都无法逃脱的局限：

- **抽样缺陷**——研究只能观察样本而非总体（40%的问卷回复率意味着60%的人的声音消失）
- **测量缺陷**——所有测量工具都是近似工具（自填问卷可能隐瞒真相、面对面访谈可能引发表演性回答、公开观察改变行为）
- **问题定义缺陷**——任何研究只能切割问题的一小片来操作化（研究"创造力"只能选视觉艺术或音乐或写作中的一种）

由此得出两条纪律：①任何单篇研究的结论都不是"已证明的事实"，而是"一份证据"；②综述者的任务不是"报告正确结论"，而是给每篇研究贴上证据强度标签。注意——证据分级 ≠ 怀疑主义：不是把什么都打上问号搁置，而是承认缺陷后仍然做出有依据的程度判断。

### 操作角色模型：像陪审员一样行动

写综述时，你的角色不是"推销员"（只选支持自己的文献），也不是"百科全书"（把文献不加判断地列出来），而是"陪审员"。四个行为规范：

1. **开庭前不带预设立场**——先把"我想证明什么"搁置，让自己成为中立的证据审理者。立场应该在听完所有"证词"之后形成。
2. **听取双方证词后权衡**——主动寻找支持和反对两方文献，比较哪方的抽样更合理、测量更可靠、证据更强，做出"A方提供了比B方更强的证据"的判断，而非"A方是正确的"。
3. **用"优势证据"标准，而非"无可置疑"标准**——实证综述用民事标准（>50%确信，即A比B更可能为真）。不需要等到所有研究完全一致才形成判断。
4. **判决书要解释推理过程**——必须在综述中告诉读者你为什么认为某方证据更强：是因为样本更大？随机分配了？还是一方普遍存在共同方法偏差？

## A1 — 书中的应用

### 案例 1：面对两篇结论相反的研究（青少年吸入剂发生率）
两篇研究报告了截然不同的数字（不到1%的一半 vs 超过5%）。不直接判定"谁对谁错"，而是检查三类缺陷：邮寄问卷回复率低（测量偏漏）、面对面访谈可能有社会期望偏差（被问者不愿承认违法行为）。结论："差异本身可能来自测量方法的差异，而非真实行为差异。"——读者获得了比"从X%到Y%不等"更有信息量的叙述。

### 案例 2：统计显著但实际效果微不足道（计算机辅助教学）
一项研究发现"计算机辅助教学带来统计上显著的进步"，老师可能据此花钱买软件。追问实际效果大小后发现：多项选择题的平均涨幅只有约1个百分点。统计显著≠实际重要——综述者有责任指出这一点。

### 案例 3：处理结果不一致的文献（校服支持率19%~52%）
差的综述只看总范围然后说"存在分歧"就完事。陪审员思维追问"为什么"：分开检查发现农村父母支持率偏低（19%~28%）、城郊父母偏高（35%~52%）。结论："总体支持率取决于两个子群体在目标人群中的占比。"——读者获得可操作的判断，而不是被丢在"我们也不知道"的模糊地带。

## A2 — 触发场景 ★

### 用户会在什么情境下需要这个 skill？

1. **读论文时陷入"这句话到底可不可信"的焦虑**——看到结论"X干预有效"，但不知道怎样判断可靠性
2. **写综述时习惯性用"研究证明了…""实验证实了…"**——需要把"证明"替换为"提供证据支持"或"表明"
3. **面对两篇结论矛盾的文献卡住**——不知道该信哪一篇，想跳过或强行选一边
4. **综述启动阶段已有立场，担心"只选符合自己立场的文献"**
5. **导师说"综述有偏见"或"你要批判性地读文献"但没给具体标准**
6. **在"学术要客观"和"综述要有论点"之间感到矛盾**——困惑于"有立场还怎么客观"

### 语言信号

- "这篇论文应该是对的……毕竟发表在好期刊上"
- "研究证明了X""实验证实了……"
- "这两篇结论完全相反，我该信谁"
- "我没有学过统计，能判断研究好不好吗"
- "我不想让自己的偏见影响综述"
- "综述要有自己的观点吗""怎么才算客观地写综述"
- "我该按什么标准判断一篇研究更可信"

### 与相邻 skill 的区分

- 与 `preread-classify-deepread` 的区别：预读分类解决"读哪篇"的效率问题；本 skill 解决"信几分"的判断问题。先有预读筛出的文献池，才有证据评估的对象。
- 与 `research-quality-checklist` 的区别：本 skill 是角色定位和行为准则（"作为陪审员该怎么想"），质量清单是具体的盘问问题（"信效度多少、效应量多大"）。先建立角色意识，再拿起清单去盘问。
- 与 `claim-vs-evidence` 的区别：两者是两种可选方案——本 skill 是**整体证据权衡**（多篇文献之间的宏观判断），后者是**单篇内部的逐句拆解**（哪句是数据、哪句是推测）。做跨研究的综合判断用本 skill，做单篇精读的微操用后者。

## E — 可执行步骤

当 skill 被激活后，agent 应按以下步骤执行：

1. **心态校准：检查绝对化语言**
   - 识别用户是否在使用"证明了""证实了""这是正确的"等措辞
   - 展示三类缺陷框架并用用户正在读的论文举例：样本能否代表总体？测量有没有系统偏差？问题定义是否只切了一小片？
   - 完成标准：用户理解了"证据强度标签"思维，完成"证明→提供证据支持"的措辞替换
   - 判停条件：若用户已在主动质疑研究质量且措辞审慎，直接进入步骤2

2. **设立"审判席"——把主题重构为可审理的问题**
   - 引导用户把综述主题表述为可辩论的问题形式："线上教学是否损害小学生的注意力"（而非"线上教学对注意力的影响"）
   - 判停条件：若主题天然没有两方辩论性质（如"X领域研究趋势概述"），改为列出"需要告知读者的关键发现"作为证词清单

3. **盘点证据库——标注"支持方""反对方""中立证人"**
   - 在文献笔记中新增"立场标签"列，每篇标注支持/反对/中立
   - 判停条件：若某一方文献明显偏少（支持15篇、反对2篇），停下来提醒：是否漏检了反对立场的研究？主动补检

4. **撰写"判决摘要"——结论 + 推理过程**
   - 引导用户写出类似："大多数研究发现A方法有效，但两项方法论最强的研究均未发现显著效果，因此现有证据支持对A方法的热情应保持审慎"——同时包含结论和推理
   - 判停条件：若用户仍倾向于不加推理的单方陈述（"多数研究发现A有效，故A有效"），要求其解释为什么认为多数一方的方法论更可信

## B — 边界 ★

### 不要在以下情况使用此 skill

- **纯理论/哲学讨论**：逻辑论证的可靠性不由抽样和测量决定，三类缺陷框架不适用
- **纯文献罗列任务**：课程作业明确要求"列出所有相关研究"而不需形成论证时，陪审员角色过度复杂化了任务
- **只有一方证据且领域极新**：领域只有3-5篇研究且全部指向同一结论时，"反对立场"可能根本不存在——不需要强行找对立面
- **用户已在使用审慎措辞且主动评估证据强弱**：不需要重复灌输

### 作者在书中警告的失败模式

- **只读摘要就引用**：摘要缺乏抽样、测量、局限细节，基于不完整信息综述=以盲引盲
- **把论断当成研究发现来报告**：将讨论部分的推测性陈述当作结果部分的经验发现复述
- **使用"证明"一词描述实证研究发现**：最典型的失败模式
- **把非实验研究称为"实验"**：用错术语误导读者对证据强度的判断
- **"未来需要更多研究"不够具体**：好的判决书要说清哪些事实还没查清、需要补充什么证据

### 作者的盲点 / 时代局限

- **"陪审员"比喻假设证据是对称的**：现实中"反对方"证据可能被系统性压制（发表偏倚、语言偏倚、基金来源偏倚）。要特别注意"缺席的证词"——检索策略说明可以部分弥补
- **AI 摘要就是二手证词**：AI 摘要往往模糊了方法论缺陷。用 AI"帮读"论文时，三类缺陷框架仍然要自己跑——不能只靠 AI 摘要下结论
- **"客观中立" vs "有立场的公正"**：陪审员模型明确指出你必须最终裁决（有立场），但立场是在听完证据之后基于权重的判断。目标是"公正"，不是"没有立场"

### 容易混淆的邻近方法论

- **怀疑主义 vs 证据分级**：不是"怀疑一切、什么都不能信"，而是"给每条证据贴强弱标签后做出有依据的判断"。区别在于有没有"程度"判断
- **元分析的量化加权 vs 质性权衡**：元分析用统计方法给证据加数学权重；本 skill 用质性推理——不会做元分析时依然能做出有依据的证据强度判断
