# 封面方案 v3 · B0期「AI时代的文献管理」——Agent+Zotero 等式视觉

**v3 核心变化**：用户定稿方向——封面主视觉用**图标等式**表达概念：
> **Agent + Zotero = AI时代的文献管理答案**

等式**不作为标题文字**，而是作为封面中央的**视觉元素**呈现（图标+符号构成），标题区保留文字钩子。本方案详细定义等式视觉的构成、图标处理、布局与生图方式。

## 二、等式视觉详细设计

### 2.1 等式的信息层级
等式由 5 个元素构成，从左到右一条水平线阅读：
`[Agent图标] —(+)— [Zotero图标] —(=)— [橙色答案胶囊]`

- **Agent 图标**：代表"你的 AI Agent 工具"（opencode / hermes 头像可选，见 2.2）
- **"+" 号**：品牌橙色粗体，连接两个工具，暗示"叠加组合"
- **Zotero 图标**：立体 Z 字图标（见 2.2）
- **"=" 号**：品牌橙色粗体横线，引导视线到结论
- **答案胶囊**：橙色圆角胶囊/气泡，白字写**「AI时代的文献管理答案」**（9字，是等式结论，非标题）

### 2.2 图标来源与处理（用户上传资产）
| 元素 | 素材 | 处理方式 |
|------|------|---------|
| Agent 图标 | `assets/icons/opencode-logo-dark.svg`（深色背景版）| 深黑底上直接可用（白色调），放白色细线圆角框内 |
| Agent 备选 | `assets/icons/hermes-icon-black.svg`（黑色头像）| 深黑底上**不可见**，需反白处理：白色描边版 or 放入白色圆角方章内 |
| Zotero 图标 | `assets/icons/zotero-z-icon.png`（立体红Z）| 保留原图标质感（红=偏色，见下方风险），放入白色细线方框 |
| Agent 彩色版 | `assets/icons/opencode-logo-light.png` | 备用，若深色版不够清晰 |

**图标与风格基准的冲突处理**：
- 系列基准（style-dna）要求"只有黑/白/橙三色 + 不要真实App截图/3D"
- 用户明确要求**体现真实图标** → 用户偏好优先，但做**融合折衷**：
  1. 图标统一放入**白色细线圆角方框**内（扁平化框体，保持几何感）
  2. Zotero 的立体红 Z 是唯一偏色元素 → 可接受为"识别锚点"（用户明确要求用这个图标），或在生图时用橙色重绘一个扁平 Z 作为备选（A/B 两版）
  3. 除图标本体外，等式结构线条全用白+橙，维持系列调性

### 2.3 答案胶囊文案（可选变体）
- 主推：**「AI时代的文献管理答案」**（直接对应口播稿关键词，9字）
- 备选A：**「答案：AI管文献」**（更短更直白）
- 备选B：**「文献管理，AI的答案」**（倒装，押标题"别手打"）

## 三、Lee 的角色（保持系列基准）

Lee 站在等式下方偏右，**仰头指向答案胶囊**（"就这个答案"的手势）或**双手按键操作**（呼应"AI直接操作文献库"卖点）。
- 表情：专注、笃定，不夸张（概念解释路线，非卡通风情绪路线）
- 通过 ref_images 传 `ai-avatar-flat.png` 锁定形象，白描风

## 四、生成方式（两段式）

### 第一步：image_gen 生成底图（含等式结构，图标留白）
按 lee-concept-illustrations prompt-template 填充：
```
Generate one standalone 3:4 vertical Chinese concept illustration.
Visual DNA: deep black solid background, flat vector, white thin lines,
brand orange only accent. Subject occupies 50-65%.
Character: Lee (ref image), standing lower-right, pointing up at the equation.
Theme: AI时代的文献管理——Agent工具+Zotero=管理答案
Structure type: Equation / Concept Metaphor
Core idea: 两个工具图标叠加=文献管理的最终答案
Scene: 深黑底上，顶部标题区；中上部水平等式——
  左一个图标框（留白，待叠加opencode），中间橙色"+"，
  右一个图标框（留白，待叠加Zotero Z），橙色"="，
  右侧一个橙色圆角胶囊，内写白字"AI时代的文献管理答案"。
Key elements: 图标框x2 / 橙色加号 / 橙色等号 / 橙色答案胶囊 / Lee
Short white labels: "AI时代的文献管理答案"（胶囊内）
Color rules: black bg, white lines, orange ONLY for + = 胶囊和强调.
Constraints: 不要在图标框里画具体logo，留空待叠加；
Lee必须出现；答案胶囊文字务必清晰拼写正确。
```

### 第二步：PIL/SVG 叠加真实图标（确保识别度）
底图生成后，用 PIL 把真实图标贴进两个留白框：
- 左框：`opencode-logo-dark.svg`（深色版白字，或 hermes 头像反白版）
- 右框：`zotero-z-icon.png`（立体Z）
- 叠加后 read_image 自检图标清晰度、位置、比例

### 第三步：cover-brand-bar C 模式拼品牌栏
左下 = 头像 + 「和Lee一起学AI 学得懂，用得上」；右下 = 🦉 + 「AI·效率·方法论」
