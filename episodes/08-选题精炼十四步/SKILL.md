# 选题精炼十四步法

> 产线位置：第6期skill包附赠 · 方向工位 · 上游 [claim-vs-evidence] / 下游 [matrix-method-topic-selection]

## R — 原文 (Reading)

> 一篇综述的主题太宽泛很可能导致综述显得肤浅，在这个主题中从一个领域跳到另一个领域，不能向读者证明你已经完全了解了关于这个主题的文献。因此，你应该考虑把你的主题重新界定得更具体一些。
>
> — 何塞·L.加尔万 & 梅丽莎·C.加尔万, 第3章

---

## I — 方法论骨架 (Interpretation)

选题不是"拍脑袋想一个感兴趣的方向"然后开始写，而是一个可以被拆解为14个具体步骤的系统操作。十四步法的核心逻辑是：**用数据库检索结果的数量作为客观信号**——结果太多说明还要缩小，结果适中（50-150条）说明进入可操作区间，结果太少需要扩大。

十四步可以分为四个阶段来理解：

**阶段一：从"总主题"到"检索信号"（步骤1-7）**。你不是给自己选一个"感兴趣的领域"，而是把宽泛兴趣（比如"儿童语言习得"）投进数据库里看看实际结果是什么样的。从中聚类出可能的子主题（如"父母在语言习得中的作用""语法结构的习得"等），再根据检索结果数量判断哪一个子主题有足够的文献支撑。如果某子主题文献太少，扩大时间范围或补充检索未发表研究（会议论文、学位论文）；如果某个子主题文献过多，继续加限定词。

**阶段二：从"检索文献"到"理解领域"（步骤8-11）**。这阶段的关键动作是找出这个领域的综述文章（了解别人已经综述了什么）、理论文章（了解这个现象为什么发生的理论解释）、以及里程碑式研究和理论家（通过反复出现的作者名溯源找到领域的奠基者）。这一阶段确保你的选题不是在一个根本没被研究过的方向，也不是在一个已经被充分综述过的方向——而是正好有足够的一手文献但还没有系统综合。

**阶段三：从"理解领域"到"写下来"（步骤12-13）**。这是十四步法最容易跳过但最重要的一步：把你的选题写成一两段"主题说明初稿"。书写会暴露思维的模糊——如果你写不清自己要综述什么，说明选题还没聚焦到位。写完后回到数据库做一次"确认检索"，看看是否漏掉了什么。

**阶段四：从"自己判断"到"外部验证"（步骤14）**。把你的主题说明拿给导师或同行看。这是十四步法的最后一道防线——导师可能告诉你这个选题仍然太宽/太窄，或者帮你指出你遗漏的文献生成来源。注意：不要跳过这一步，自己闭门精炼选题是最高风险的操作。

一个小但重要的策略打包在步骤8-9中：**从最新研究回溯**——拿到最新文章后复制其参考文献列表，比较多个最新文章的共同引用文献，找到领域核心文献。对于陌生领域，这比从早期文献向前翻更高效。

## A1 — 书中的应用 (Past Application)

### 案例 1：从"第二语言习得"到可操作的主题

- **问题**：总主题"第二语言习得"太大，数据库检索结果无数，不可能在一学期内写完综述。
- **方法论的使用**：应用十四步法的阶段一——对检索结果的标题和摘要进行聚类，分出五个子主题："影响语言习得的障碍""父母的作用""西班牙语儿童的语言习得""语法结构与类别""幼儿语言习得"。发现每个子主题的文献量都还在可操作范围内。
- **结论**：不是所有的子主题都适合——需要根据用户（综述者）的学科做二次选择。如心理学方向选"语言障碍儿童的语言习得"，语言学方向选"语法结构和范畴的习得"。
- **结果**：从"第二语言习得"缩小到了"语言障碍儿童的早期发音发展"，进入可操作区间。

### 案例 2：从"儿童语言习得"到聚焦"动词语法特征"

- **问题**：即使已经限定"4岁以内讲英语的儿童"，主题"儿童语言习得"仍然太宽——同时覆盖了声音和语法两个庞大的子系统。
- **方法论的使用**：应用步骤12-13——写主题说明初稿，发现了问题：初稿试图"从最早的声音开始逐步发展到完整的句子"。通过进一步聚焦到"描述儿童的动词使用和动词短语特征"，主题有了明确的操作边界。
- **结论**：改进后的主题是"描述儿童如何获得描述时间和介绍时间的能力，包括动词的使用和动词短语中包含的其他特征。"——这不再是"所有的语言习得"，而是一篇有望在一学期内完成的文献综述。
- **结果**：主题从无限大缩小到了可操作的"一个语言特征"维度。

### 案例 3：用关键词"理论"和"文献综述"找到领域建筑图

- **问题**：用户想综述"社交恐惧症"，但直接搜这个主题出来成百上千篇，完全不知道从哪个角度切入。
- **方法论的使用**：应用步骤8-9——在检索中添加"理论"关键词（如"social anxiety AND theory"），找到了一篇关于社交恐惧症性别差异的元理论文章（Martel, 2013）。再添加"literature review"关键词在TI字段检索，找到两篇已有的物质滥用治疗综述。
- **结论**：综述文章告诉用户"别人已经综述了什么、还有什么没综述"；理论文章告诉用户"这个领域有哪些核心概念和争论"。
- **结果**：用户不再在原始文献堆里迷失，而是站在"综述"和"理论"的制高点俯瞰领域全貌后再决定从哪儿切入。

### 案例 4：通过反复出现的名字找到班杜拉

- **问题**：用户在研究"社会学习理论"在儿童行为中的应用，需要找到这个领域的奠基性研究但不认识"班杜拉"这个名字。
- **方法论的使用**：应用步骤10——在阅读文献时注意反复出现的作者名字（"Albert Bandura"在几乎所有社会学习理论文献的第一句都被引用），然后用作者名字（AU字段）+ 关键词在数据库检索他的早期研究。
- **结论**：找到了Bandura(1969)的社会学习道德判断研究——这是社会学习理论最早的系统实证研究之一。
- **结果**：用户不仅有了"班杜拉"这个名字，而且有了他的具体早期研究作为综述的里程碑引用，整个综述的时间线和理论溯源有了支点。

### 案例 5：数据库检索结果数量作为客观信号

- **问题**：用户觉得"我觉得这个主题差不多可以了"，但完全凭感觉判断。
- **方法论的使用**：应用步骤3-4——用具体的限定词（AND/OR组合）反复缩小检索范围，直到输出数量落在一个可感的区间（作者建议50-150篇为适中）。
- **结论**：如果加了"AND elementary students"还太多，再加"AND art education"；如果加了限定后结果太少，去掉一个限定或扩大时间范围。检索结果的数量不是主观感觉——它是一个可以在屏幕上看到的数字。
- **结果**：选题不再靠感觉，而是可以用检索结果的数量作为"往前一步"还是"后退一步"的客观路标。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. **学期开始，教授布置了"自己选主题写文献综述"**——用户完全不知道从哪儿开始，面对空白文档焦虑。
2. **用关键词搜数据库出来成千上万条结果**——用户被大量检索结果吓到，不知道该从哪条入手筛选。
3. **导师说"选题太宽泛了/不够聚焦"**——用户已经花时间检索了但不知道该往哪个方向缩小。
4. **对领域完全陌生，不知道谁是奠基者、那几篇是必读的**——用户需要快速建立领域认知地图。
5. **选题已经缩小了，但不确定是不是"太窄了"**——需要检验自己的选题有没有达到"足够文献支撑"的最低门槛。
6. **选题已经确定了，但需要写一份主题说明给导师审批**——需要把自己的选题从"脑子里想的口头描述"变成"一段有边界的书面说明"。

### 语言信号 (用户的话里出现这些就应激活)

- "我不知道该写什么主题"
- "这个领域太大了，不知道怎么缩小"
- "导师说我的选题太宽/太窄"
- "搜出来几千篇，不知道从哪篇开始读"
- "怎么找到这个领域的奠基人/经典论文"
- "我的主题词搜出来的文献够不够写综述"
- "我要写一个学期论文，但想不到写什么"
- "怎么把一个感兴趣的领域变成可操作的研究主题"
- "从哪里开始检索比较有效率"

### 与相邻 skill 的区分

- 与 `preread-classify-deepread` 的区别：本 skill 解决的是"找什么"（选题和检索策略），后者解决的是"找到后怎么读"（阅读策略）。时间线上本 skill 在前。
- 与 `spreadsheet-note-system` 的区别：本 skill 结束时输出的是"一个聚焦好的可操作主题清单+主题说明"，后者才开始为筛选出的文章建电子表格。但步骤11（保存引文到文件夹）是过渡——为后续建笔记系统做准备。
- 与 `literature-search` 的区别：本 skill 包含文献检索策略（步骤1-11），但不是单纯的检索工具——它的目的是"用检索作为工具来精炼选题"，最终输出是一个聚焦的、可操作的综述主题而非一堆检索到的文章。检索动作本身交给 literature-search 执行。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **确定用户当前状态：有无初始主题？有无数据库访问？**
   - 完成标准：明确用户是(a)完全从零开始（需要先找一个宽泛兴趣领域）、(b)有宽泛兴趣但没检索过、(c)已检索过但结果太多、(d)已缩小但不确定是否到位。
   - 判停条件：若用户说"我已经有完整主题且检索结果在50-150篇范围"，直接跳到步骤5做主题说明。

2. **从宽泛到聚类：帮助用户对检索结果分组**
   - 完成标准：用户能列出3-5个从检索结果中聚类出的子主题。如"儿童语言习得→语音发展/语法习得/双语儿童/语言障碍/父母输入"。
   - 判停条件：若检索结果<10篇，先跳到"扩大文献列表"（扩大时间范围、补充未发表文献、放宽关键词）。

3. **用检索结果数量判断：选哪一个子主题进入"可操作区间"**
   - 完成标准：每个候选子主题有一个检索结果数量估计（50-150为理想区间），用户据此选择1个最合适的子主题。
   - 判停条件：所有子主题都不在区间内（全太多或全太少），调整关键词策略后重新进入步骤2。

4. **找综述、理论和里程碑——建立领域认知地图**
   - 完成标准：用户找到了(a)1-2篇该子主题已有的综述文章、(b)1-2篇关键理论文章、(c)3-5位反复出现且被广泛引用的研究者（里程碑式理论家）。
   - 判停条件：若子主题太新以致没有综述或理论文章（这是好消息——意味着空白点），标记为"前沿空白区"但仍需找到里程碑研究者。

5. **写主题说明初稿并拿给他人看**
   - 完成标准：一段100-200字的主题说明陈述了：(a)要综述的文献范围、(b)主要关注什么群体/变量/时间段、(c)综述的目的。用户已将此主题说明发给了导师/同行/或至少大声读给自己听了一遍。
   - 判停条件：写主题说明时发现自己写不清——说明选题还没聚焦好，返回步骤2。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **用户已有明确且可操作度高的选题**：如"XX大学2020-2025年间本科生学术拖延行为的正念干预效果研究"——这已经极其聚焦，十四步法大部分步骤在用户身上都是多余的。
- **用户的论文是元分析且数据库自动输出全部相关研究**：元分析有自己独立的检索和纳入/排除标准（如PRISMA流程图），不需要十四步法的"聚焦→再聚焦"逻辑。
- **用户的任务不是写综述而是写其他类型的论文**：如实证研究论文的引言部分只做简要文献回顾——选题已由研究问题决定，不需要独立精炼。

### 作者在书中警告的失败模式

- **主题太宽泛（ce02）**：完成后的综述"从一个领域跳到另一个领域"，肤浅且不能证明综述者已通晓该主题的文献。这是十四步法要防止的核心失败。
- **没找里程碑研究就开始写**：缺少里程碑研究对学位论文是"严重缺陷"——作者在步骤10中明确强调这一点。
- **跳过"主题说明"步骤直接开始阅读**：没有写成文字的主题说明不能被客观检验——"脑子里觉得清楚了"不等于真的聚焦了。
- **跳过步骤14（征求导师反馈）**：自己闭门精炼选题容易产生盲点，特别是遗漏了导师知道的文献生成来源或学术传统。

### 作者的盲点 / 时代局限

- **数据库假设全部为付费订阅式**：作者假设学生通过大学图书馆访问EBSCO、PsycINFO等付费数据库。当前学术生态中，开放获取数据库（Google Scholar、Semantic Scholar、arXiv、SocArXiv）已成为许多学生的主要入口——十四步法中的具体数据库操作（如EBSCO截图示例）需要适配。
- **检索策略未涵盖AI辅助发现**：作者未涉及LLM辅助选题（如让AI根据宽泛关键词推荐子主题）、AI引文地图工具（Connected Papers、Research Rabbit）等。这些可以作为十四步法的"加速器"而非替代。
- **50-150篇的目标区间取决于任务类型**：一学期的本科综述可能15-30篇也够。十四步法中的数量区间应根据任务类型灵活调整。
- **未涉及中文文献检索体系（知网、万方、CSSCI）**：步骤1中的"设置代理服务器和VPN"在中国大学环境中是另一种形态（知网校内访问、CARSI认证等），但聚类、理论文章识别、里程碑研究者追溯的逻辑完全适用。

### 容易混淆的邻近方法论

- **"精炼=缩小"的误解**：十四步法不是单向的"一直缩小"。步骤5说"如有必要扩大文献列表"，步骤7说"检索综述文章"，步骤8说"检索理论文章"——每一步都是双向的，检索结果太少就要往回走。目标是"精准"，不是"越窄越好"。
- **系统综述（Systematic Review）的PRISMA vs 本 skill**：PRISMA要求预注册检索策略+双盲筛选+纳入排除流程图，适用于发表级别的系统综述。本 skill 的十四步法是为学期论文和学位论文阶段的综述设计的——也需要说明检索策略以确保可追溯，但不需要PRISMA那样的全面性。
