# 格雷准则研究问题筛选 (Gray's Criteria)

> 产线位置：第10期 · 方向工位 · 上游 [matrix-method-topic-selection] / 下游 [research-focus-anti-guerrilla]

## R — 原文 (Reading)

> 评判高影响力研究的标准是由吉姆·格雷 (Jim Gray) 总结出来的……1999年，在图灵奖颁奖典礼上，他提到一个好的研究问题应该具备以下几个条件：明显的益处；描述简单；尚不具有明确的解法；解决方案具备可测试性，大问题可以拆分成多个子问题……我们不妨增加一个第五条：要确保研究中数据获取的可靠性以及足够的数量。
>
> — 凌晓峰、杨强，《学术研究：你的成功之道》第4章

---

## I — 方法论骨架 (Interpretation)

格雷准则是一个**研究问题的五维度质量筛**。它不是帮你"找到"新想法，而是帮你"判断"已有想法是否值得投入数年去攻克。五条准则之间是**层层递进的过滤逻辑**：

1. **明显的益处（Why）**：这个问题对社会或科学领域有贡献吗？如果答案不明确，做再久也只是自娱自乐。
2. **描述简单（What）**：能不能在一分钟内，用非专业人士能听懂的语言讲清楚？这一条检验的是问题的**核心清晰度**——真正重要的问题，内核往往简单。作者将此称为"电梯描述法"（讲给祖母听）。
3. **尚不具有明确的解法（Novelty Gap）**：这个问题还没有被彻底解决。注意——不是"没有人做过"，而是"没有人做出过公认的好解法"。如果现有解法已经足够好，再做的空间就很小。
4. **可测试且可分解（How）**：解决方案能否被实验/理论验证？大问题能否拆成可观察中间结果的子问题？这一条是五条中**最关键**的——一个永远无法验证的假说不是研究，是玄学。
5. **数据可靠且足够（Feasibility）**：是否有可靠的数据源？数据量是否够支撑实验？这是作者补充的实操底线——很多好想法死在"没有数据"上。

五条准则本质上是把**新颖性 + 影响力 + 可行性**拆成了可操作的检查点。前三条回答"值不值得做"，后两条回答"做不做得了"。

## A1 — 书中的应用 (Past Application)

### 案例 1：博士生A2 — 迁移学习（学术型）

- **问题**：A2 想做超出当前最优水平的研究，对迁移学习产生兴趣。具体方向：如何将从文本数据中学到的模型迁移到图片数据中，帮助图片分类？
- **逐条对照**：
  - ① 益处：减少对昂贵人工标注数据的依赖，提升搜索引擎、社交网络等应用的精度 → **通过**
  - ② 描述简单："用文本训练计算机分类文本的能力，然后让这个能力帮助分类图片" → 两句话能说清 → **通过**
  - ③ 尚无明确解法：训练数据和测试数据分布不同（文本 vs 图片），传统假设不成立，现有工作没有公认的通用方案 → **通过**
  - ④ 可测试且可分解：正确分类的图片百分比作为评价指标；可从"先用现有翻译器"→"自学习翻译器"→"变换文本/图片类型测试鲁棒性"逐层推进 → **通过**
- **结论**：迁移学习通过全部格雷准则，成为 A2 的博士论文课题。
- **结果**：围绕该课题发表多篇顶级会议论文，博士论文顺利通过。

### 案例 2：博士生B2 — 搜索条目分类（实验型）

- **问题**：B2 想做大规模应用研究，瞄准搜索引擎中的"搜索条目分类"——自动将用户搜索词分类，联动广告推荐。
- **格雷准则验证**：该问题借助迁移学习将已有的标注数据能力扩展到新领域，益处明确（用户体验 + 广告收入双赢），描述简单，方案可测试且可借助搜索引擎公司的大规模数据验证。B2 以实习生身份进入搜索引擎公司获取数据（对应第五条）。
- **结论与结果**：通过格雷准则筛选，B2 围绕此课题在工业界研究环境中完成了博士研究。

### 案例 3：博士生C2 — 在线广告推荐（创业型）

- **问题**：C2 毕业后想创业，选择"在线广告推荐"作为研究课题——这是一个跨学科（经济学 + 博弈论 + 人机交互 + AI）的商业应用问题。
- **格雷准则验证**：广告推荐的益处不言而喻（商业价值巨大），第五条的"数据获取"尤为关键——C2 通过参加学术和商业会议、以志愿者身份参与研讨会来建立人脉和数据渠道。
- **结论与结果**：通过准则筛选，C2 在读博期间积累了商业应用经验，为创业做准备。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 用户手头有几个候选研究方向，不知道选哪一个深入——需要一个**结构化打分标准**
2. 用户已经在某个课题上做了一阵，开始怀疑这个方向"值不值得"——需要**客观的停-换-继续决策框架**
3. 用户被导师/同行评价说"研究问题不够好"，想系统地重新审视——需要**可辩护的标准来论证自己的选题**

### 语言信号（用户的话里出现这些就应激活）

- "这个研究方向值得做吗？"
- "怎么判断一个研究问题好不好？"
- "我的研究问题能支撑博士论文吗？"
- "这几个课题选哪个？"
- "我的课题会不会太窄/太宽/太浅了？"
- "导师说我题目不好，我该怎么证明它好？"

### 与相邻 skill 的区分

- 与 `matrix-method-topic-selection`（棋盘法）的区别：棋盘法是**"找"**——通过文献梳理构建问题×方法矩阵，发现尚未被研究的空白格（候选池）。格雷准则是**"筛"**——在已经列出的候选池中，用五条标准逐项打分，过滤出值得投入的课题。二者是前后衔接的流水线：棋盘法出候选 → 格雷准则筛选 → 确定课题。
- 与 `academic-brainstorming-ideation`（头脑风暴法）的区别：头脑风暴是发散的、量产的，格雷准则是收敛的、过滤的。头脑风暴不要求验证想法质量，格雷准则恰恰是质量验证。
- 与 `thesis-blueprint-planning`（博士论文蓝图）的区别：格雷准则用于"选题前"的筛选，蓝图规划用于"选定后"的路线设计。不存在 overlap。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **电梯描述检验（先测第二条）**
   - 让用户用 ≤3 句通俗中文描述研究问题，假想听众是一位非本专业的普通人
   - 完成标准：agent 能用自己的话复述该问题且无歧义
   - 判停条件：若用户自己都无法说清 → 问题大概率不成熟，建议回到棋盘法/头脑风暴重新澄清

2. **逐条打分（1-5分量表）**
   - 对五条准则逐一评分，每一条都要求用户提供证据（不是"我觉得"）：
     - ① 明显的益处：证据 = 列出至少 2 个具体受益人群/场景
     - ② 描述简单：证据 = 用户刚才的电梯描述是否通过
     - ③ 尚无明确解法：证据 = 至少 1 篇近年综述中指出的 open problem，或现有方法的关键缺陷
     - ④ 可测试可分解：证据 = 列出 3-5 个子问题 + 每个子问题的实验方案雏形
     - ⑤ 数据可靠且足够：证据 = 数据来源 + 获取可行性（公开数据集/合作/自采集）
   - 完成标准：五条均有分数和证据
   - 判停条件：任何一条 ≤2 分 → 标记为 🔴 高风险；3分 → 🟡 需补充论证；≥4分 → 通过

3. **汇总决策：通过 / 修补 / 放弃**
   - 全绿（全部 ≥4 分）：确定为正式课题，进入博士论文蓝图规划阶段
   - 有黄（有 3 分项）：列出修补方案——哪条弱就补哪条（如数据不够 → 起草数据合作计划；可测试性差 → 重新设计子问题分解）
   - 有红（有 ≤2 分项）：放弃该候选，**回到棋盘法重新找**——这不是失败，是节省时间的理性决策
   - 完成标准：用户明确说出下一步行动（确定 / 修补计划 / 回棋盘法）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已经在执行一个确定的课题（如二年级、已发表相关论文），此时应用格雷准则只会造成不必要的自我怀疑。格雷准则用于**选题前**，不是**执行中**。
- 用户的领域属于纯理论学科（如理论物理、纯数学），第④条"可测试性"和第⑤条"数据获取"的定义需要重新翻译，不能用计算机科学的实验范式直接套用。
- 用户处于文献检索/阅读积累阶段——此时应先用棋盘法或批判性创造性阅读法，而不是急于筛选。

### 作者在书中警告的失败模式

- **跳过格雷准则直接凭兴趣+导师一句"可以试试"就扎进去**——导师可能不了解你的全部情况，最终结果的可行性由你自己负责验证
- **只做文字描述不拿证据**——作者强调"可测试性"是五条中最关键的一条，如果你的研究问题无法设计可观测的实验/检验，很可能不是"研究"而是"随笔"
- **忽视第五条（数据）**——作者见证过大量学生"有好想法、有好算法、有系统，却卡在没有数据"——这一条必须在选题阶段就确认，而不是做到一半才发现

### 作者的盲点 / 时代局限

- **来自阶段 0 批判**：全书写于 2012 年深度学习革命前夕，案例全部来自传统机器学习领域。对 2026 年的大模型/LLM 科研范式，第③条"尚无明确解法"和第④条"可测试性"的阈值可能需要重新校准——在大模型时代"打榜"式研究泛滥，一个 SOTA 分数的提升 ≠ 有真正的新解法。
- **对"描述简单"的过度强调**：有些真正开创性的工作（如 Shannon 的信息论、Hinton 的深度信念网络）在提出时并不"简单"，需要较多前置知识才能理解。"描述简单"更适合作为**检验理解深度**的工具，而非硬性门槛——如果你能用简单语言讲明白，说明你真正懂了；如果你只能糊弄过去，说明你自己还没想清楚。
- **精英主义假设**：作者假设研究者处于资源充足、导师负责的理想环境。现实中，很多学生受限于导师方向、实验室资源、毕业倒计时，无法完全自由地按格雷准则筛选。此时格雷准则应作为"自我校准"而不是"不可撼动的教条"。

### 容易混淆的邻近方法论

- **与"可行性分析"**：可行性分析通常只关注资源、时间、技术栈是否到位，对应格雷准则的④⑤两条；格雷准则额外覆盖了价值判断（①②③）。格雷准则 = 可行性 + 影响力评估。
- **与"SMART 目标"**：SMART 是通用目标管理框架，格雷准则是专为学术研究问题设计的筛选器，维度不完全对应（如 SMART 不包含"有无现存解法"）。
- **与"ICE 评分法"（Impact×Confidence×Ease）**：ICE 是产品开发领域的优先级排序工具。格雷准则的①②对应 ICE 的 Impact，④⑤对应 Ease，但新增了③（新颖性），更适合学术场景。
