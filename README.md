# paper-writing-skills · 论文写作 Skills 系列

面向 AI Agent（opencode / Claude Code / OpenClaw 等支持 SKILL.md 格式的工具）的学术论文写作 Skill 集合。每个 skill 装进你的 Agent，就能"一句话搞定"一个科研环节。

## 快速上手（给 AI 的一句话）

> 把本仓库任意 skill 文件夹复制到你的 skills 目录，对你的 Agent 说"帮我配置 XXX"即可。
> 每个 skill 自带 `doctor` 环境自检，缺什么它会告诉你怎么补。

## 配套工具（已发布）

| Skill | 定位 | 一句话 |
|---|---|---|
| [literature-search-starter](./literature-search-starter/) | 文献检索引擎底座 | 一条命令搜全网论文：五源联搜、自动去重、零第三方依赖 |
| [zotero-cite](./zotero-cite/) | 文献入库与引用生成 | 把论文写进 Zotero、自动去重核验、生成 Word 可直接用的活引用片段 |

## 主系列路线图（七工位 · 19 期）

> 产线逻辑：检索(0) → 筛选(1-3) → 精读(4-7) → 方向发现(8-11) → 综述撰写(12-14) → 正文撰写(15-17) → 投稿返修(18)。现实是循环，视频按线性讲。

| 期 | 工位 | Skill | 一句话 |
|---|---|---|---|
| 0 | 检索引擎 | literature-search | 一条命令搜全网论文 |
| 1 | 筛选 | 预读→分类→详读 | AI 批量筛论文：3 秒判断该不该读 |
| 2 | 筛选 | 研究质量评估清单 | 不是所有论文都值得信：定量13条+定性8条 |
| 3 | 筛选 | 证据思维 | 所有研究都有缺陷，像陪审员一样读 |
| 4 | 精读 | 批判性创造性阅读 | 30%读 70%想 |
| 5 | 精读 | 九列笔记法 | 把一篇论文榨成一张表 |
| 6 | 精读 | 文献深度分析十二准则 | 读出作者自己都没意识到的漏洞 |
| 7 | 精读 | 论断vs证据 | 别被论文唬住 |
| 8 | 方向 | 选题精炼十四步 | 选题太大？用检索数据缩小 |
| 9 | 方向 | 棋盘法 | 一张棋盘定位研究空白 |
| 10 | 方向 | 格雷准则 | 空格子≠好课题：5 条标准 |
| 11 | 方向 | 课题聚焦反游击战 | 博士生最大的坑 |
| 12 | 综述 | 笔记→主题大纲 | 打开空白文档先定论点 |
| 13 | 综述 | 注释化vs综合 | 每段以作者名开头？伪综述 |
| 14 | 综述 | 空白点与未来方向 | 拒绝"需要更多研究"套话 |
| 15 | 正文 | 金字塔写作法 | 论文=逻辑论证五步骨架 |
| 16 | 正文 | 10/30可读性检测 | 投稿前最后一道关 |
| 17 | 正文 | 终稿自检 | 读者永远是对的+自查清单 |
| 18 | 返修 | 回复审稿人 | 从拒稿到录用 |

> 主系列各期陆续上线；加更储备：学术头脑风暴、博士论文蓝图。

## 安装

把目标 skill 整个文件夹复制到你的 skills 目录：

| 工具 | 目录 |
|---|---|
| opencode | `~/.config/opencode/skills/` |
| Claude Code | `~/.claude/skills/` |

## 约定与安全

- 每个 skill 入库文献前会经 Crossref 权威核验（杜绝编造/错误 DOI），入库后回读比对确认
- API key 只存本地文件，绝不进代码/日志
- 写操作（删除/移动）执行前须用户确认
