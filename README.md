# paper-writing-skills · 论文写作 AI Skills

「和Lee一起学AI」论文写作全流程 AI 技能集，覆盖**检索 → 筛选 → 精读 → 方向 → 综述 → 写作 → 投稿**。

每个 skill 是独立目录（内含 `SKILL.md` 使用说明），可直接复制到你常用的 AI 工具中使用。

## 按期数分类（主题）

| 期数 | 主题 | 涉及 Skills |
|---|---|---|
| 第0期 | 文献检索 | `literature-search` |
| 第1期 | 预读分类详读 | `preread-classify-deepread` |
| 第2期 | 研究质量评估 | `research-quality-checklist`（含 `evidence-thinking`） |
| 第3期 | 批判性创造性阅读 | `critical-creative-paper-reading` |
| 第4期 | 九列笔记法 | `spreadsheet-note-system`（含 `deep-article-analysis`） |
| 第5期 | 论断 vs 证据 | `claim-vs-evidence` |
| 第6期·上 | 棋盘法选题 | `matrix-method-topic-selection` |
| 第6期·下 | 格雷准则筛选 | `grays-criteria-problem-evaluation` |
| 第7期 | AI 帮你缝综述 | `notes-to-outline-synthesis` · `annotative-vs-synthetic-writing` · `blank-spots-and-future-directions` |
| 第8期 | AI 帮你写正文 | `top-down-pyramid-writing` · `ten-thirty-readability-test` |
| 第9期 | AI 帮你投稿 | `final-self-edit-checklist` · `response-to-reviewers` |
| 番外 B0 | AI 文献管理 | `zotero-cite` |
| 番外 B1 | 学术头脑风暴 | `academic-brainstorming-ideation` |
| 番外 B2 | 博士论文蓝图 | `thesis-blueprint-planning` |

> 第6期·上的 skill 包另含 `topic-refinement`（选题精炼十四步）、`research-focus-anti-guerrilla`（课题聚焦反游击）。

## 安装使用

复制 `skills/<对应目录>` 到你用的 AI 工具 skills 目录即可：

| 工具 | 目录 |
|---|---|
| opencode | `~/.config/opencode/skills/` |
| Claude Code | `~/.claude/skills/` |

每个目录内的 `SKILL.md` 说明了该 skill 的触发条件与用法。

## 来源

Skills 蒸馏自《学术研究：你的成功之道》（Crafting Your Research Future）与《文献综述写作》（Writing a Literature Review）。
