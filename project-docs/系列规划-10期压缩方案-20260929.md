## 一、单期价值判定原则（从已发布两期反推）

00期和B0期能跑出来，共性是：**钩子后8-20秒必须让观众"看见结果"**（30秒搜完全网 / 一键入库+活引用），即 skill 的价值在前20秒可感知。因此单期成立的条件：

1. **痛点够硬**：观众自己正在疼（不是"应该会疼"）；
2. **结果可演示**：AI跑一遍有肉眼可见的产出；
3. **与其他期不重叠**：独有交付物，而非另一期的子集。
