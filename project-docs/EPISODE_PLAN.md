## 0. 每期制作约定（v2.0 增补）

- **制作流程以 `short-video-workflow/SKILL.md` 为准**：Step 0 选题验证 → 0.5 爆款调研 → 1 主副类型 → 2 物料选配 → 3 制作计划 → 4 口播稿 → 5 封面 → 6 发布物料 → 6.5 成片 → 7 复盘
- **主类型**：技能交付（短打型 60-120s）；**副类型**：Prompt交付（skill 压缩包）
- **形式**：口播 + slides 截图（竖屏 3:4）+ 音乐；品牌元素 = Lee 数字形象 + 品牌栏 + 🦉角标
- **统一结构**：痛点开场 → 装 skill（一条指令演示）→ 核心方法拆解 → 效果展示 → 评论区自取 + 下期串场
- **🔴 价值前置铁律（2026-09-29 新增）**：钩子后 8-20% 必须完成一次"看——结果演示"，超过 20 秒见不到 skill 产出物即失败。写稿先回答：**这期的"30秒全出来了"是什么？**
- **🔴 语感基准**：以第6期上下两集（棋盘法v3、格雷准则v1）定稿为标杆——AI 做主语、二人称、口语毛边、禁用"你有没有遇到过""这才是AI时代的XX"等公式句堆叠
- **去重规则**：合并期内的子 skill 在正片只做一句勾连（如"那只是12条里的第七条"），正文不重复已讲内容
- **串场规则**：每期开头 1 句接住上期预告，结尾 1 句预告下期（见下方串场链）
