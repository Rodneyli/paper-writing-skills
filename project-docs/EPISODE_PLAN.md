## 0. 每期制作约定

- **制作流程以 `short-video-workflow/SKILL.md` 为准**（Rod 抖音工作流 v2.4）：Step 0 选题验证 → 0.5 爆款调研 → 1 主副类型 → 2 物料选配 → 3 制作计划 → 4 口播稿 → 5 封面 → 6 发布物料 → 7 复盘。每期一个项目文件夹 `YYYY-MM-DD-技能交付-选题名/`，project.md 为总控台
- **主类型**：技能交付（短打型 60-120s）；**副类型**：Prompt交付（skill 压缩包）
- **形式**：图文 slides（沿用第 0 期：口播 + slides 截图 + 音乐），竖屏 3:4
- **统一结构**：痛点开场 → 装 skill（一条指令演示）→ 核心方法拆解 → 效果展示 → 评论区自取 + 下期串场
- **发布物**：口播稿 + 发布物料（标题×2、封面标题、标签、正文、置顶评论、评论区话术）+ skill 压缩包
- **品牌元素**：猫头鹰头像 + 品牌栏（沿用第 0 期定稿版式；视觉规范见 `short-video-workflow/references/visual-style-guide.md`）
- **串场规则**：每期开头 1 句回顾工位进度（"上期我们……今天进入 XX 工位"），结尾 1 句预告（见 SUITE_INDEX 第 6 节指针表）
- **工作流调度的部分 skill 本环境没有**（hot-content-research、cover-brand-bar、echart 等），制作时用等价能力替代
