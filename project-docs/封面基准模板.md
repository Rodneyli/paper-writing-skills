# 论文写作Skills系列 · 封面基准模板（v1 定型）

> 2026-07-27 由主人确认第1期封面定型为系列基准模板。后续各期封面在此基础上仅替换主题元素，不改框架。
> 基准成品：`projects/论文写作Skills分享/01-批判性创造性阅读/定稿/封面.png`
> 无底栏原图：`imgs/260727_15_生图/cover01fix2.jpg`

## 四大固化要素

### 1. 构图：左人物右标题
- 左侧：Lee 卡通形象（bold-graphic 粗黑描边高对比插画风），半身、有手部动作，占画面左 1/2
- 右侧：主标题大字（白色特粗黑体感，全中文），两行以内，右对齐占据右上→右中区域
- 深黑底，仅黑+白+品牌橙三色

### 2. 刊头：左上角纯文字角标
- 格式：「论文写作Skills·第N期」
- 橙色、纯文字（无底框无图形），左上角固定位置
- 仅更换期数 N

### 3. 卡片符号：亮卡动作 + 卡面写本期主题
- 人物手持发光卡片举至面部高度（卡牌带橙色辉光，是全图视觉锚点）
- 卡面写本期核心主题词（第1期="Skill"，白色特粗字）
- 英文字必须横向从左到右排列，禁止竖排/拆字堆叠
- 每期替换卡面主题词即可

### 4. 胶囊：方法论品牌标签
- 橙色椭圆胶囊，内写本期方法论口号（第1期="30%读·70%想"，黑色粗字）
- 位置：右下区域，与主标题同侧
- 每期替换口号

### 5. 品牌栏（拼接待办项，非生图内容）
- 生图完成后用 cover-brand-bar PIL 版拼接：默认 C 模式（框内浮层）、品牌 `lee-xue-ai`
- 配置参考：`projects/论文写作Skills分享/01-批判性创造性阅读/brand-bar-config.json`

## 每期可变项
- 卡面主题词、胶囊口号、刊头期数、人物动作与表情（围绕本期 Skill 主题）
- 主标题文案（全中文，白色特粗）

## 不可动项
- 画幅 3:4 竖版、深黑底、三色体系、bold-graphic 风格、四大要素相对位置
- 修改封面时遵守"最小改动原则"：只改用户点名的元素，禁止重设计整张图；编辑类生图必须锁定画面范围（禁止放大/裁切、头部完整）

## 工艺路线（2026-07-27 新增，02期复盘教训）

### 正确路径：整张直出，禁止分步叠字
- **一次生成整张封面**（文字+插画一体），不走"生成插图→编辑叠字"分步流程
- 原因：底层模型在编辑模式叠加文字时必然重绘底图，无法像素级保真。连试6轮均出现插画变形/元素复制/配色漂移。01期用整张直出一次成功，02期绕了分步弯路后回到直出路线一次成功
- **封面可直接 AI 带字**（中英横排），插图才必须无文字

### 双 ref 锚定策略
- **风格 ref**：上一期定稿封面（锁调性、构图、配色、字体风格）
- **人物 ref**：Lee 数字形象 `assets/avatar/ai-avatar-flat.png`（锁人物身份外观）
- 一张图比一千字风格描述更精准，不写"bold-graphic""黑白橙三色"以外的风格文字

### 生成 prompt 配方（每期复用）
```
粗黑描边扁平矢量插画，bold-graphic高对比风格。左人物右标题构图：左侧人物半身像（图2中形象外观不变），右侧为主题视觉元素。深黑底色，全画面仅用黑白橙三色。文字三层：左上橙色刊头「论文写作Skills·第N期」+ 右上白色特粗主标题 + 橙色椭圆胶囊方法论口号。Avoid: 写实风格、3D质感、渐变色、游离文字、水印。3:4比例
```
