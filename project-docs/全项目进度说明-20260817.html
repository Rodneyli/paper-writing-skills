05制作工作流规则（v2.5 硬约束）

接手者制作任何一期都必须遵守以下规则。完整版见 short-video-workflow v2.5 SKILL.md。

🖼 封面风格（系列统一基准 · 硬约束）

  • Lee 数字形象（黑色短发/圆眼/深灰圆领T恤/扁平矢量）
  • 深黑背景极简矢量 + 品牌橙唯一强调色
  • 顶部标题区：橙色角标「论文写作Skills·第N期」+ 白色粗体主标题 + 副标题
  • 左下品牌栏：头像 + 「和Lee一起学AI 学得懂，用得上」
  • 生图必须 ref_images 传 ai-avatar-flat.png + mode="生图"
  • 🚫 禁止 bold-graphic 粗黑漫画风、左右分屏卡通对比、多色撞色

⏸ 审核节点（护栏14 · 硬约束）

以下四个节点必须停下等用户确认，禁止闷头做完：

  • ① Step4 口播稿定稿后
  • ② Step5 封面方案/风格确认后（生图前）
  • ③ 封面底图生成后（自检+确认后拼品牌栏）
  • ④ Step6 发布物料成稿后

用户喊「先停」即停。

📁 定稿文件夹（标准结构）

  • 标准项目结构新增 09_定稿/（每期必建）
  • 最终交付物统一归档到定稿，中途版本不进
  • B0 期已建 定稿/ 文件夹
制作流程：Step 0 选题验证 → 0.5 爆款调研 → 1 主副类型 → 2 物料选配 → 3 制作计划 → 4 口播稿 → 5 封面 → 6 发布物料 → 7 数据复盘
📐 画幅与物料参数：3:4 竖版（1080×1440）硬约束；目标时长 60-120s（B0期=90s）；口播 3-4 字/秒；每期发布物 = 口播稿 + 发布物料（标题×2、封面标题、标签、正文、置顶评论）+ slides + skill 压缩包。
